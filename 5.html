가계부 미니앱 만들기

아티팩트모두 함께30분

코딩은 전혀 몰라도 됩니다. 오늘의 최종 목표입니다.

🔴 여기부터 새 대화에서 — 꼭!
왼쪽 위 [새 대화] 를 눌러 빈 대화를 여세요.
앞의 영수증 대화를 그대로 이어 쓰면 사진 8장이 매번 따라다녀 무료 한도가 금방 소진되고, 앱이 완성되기 전에 멈춥니다.
새 대화에는 ④번에서 받은 엑셀 파일만 필요합니다.
프롬프트 6 — 앱 만들기 (새 대화에 그대로 붙여넣기)모두 함께
간단한 가계부 웹앱을 HTML 파일 하나짜리 아티팩트로 만들어줘. 날짜 / 내용 / 카테고리 / 결제수단 / 금액을 입력하면 목록에 쌓이고, 카테고리별 합계와 전체 합계가 아래에 보이게 해줘. 카테고리는 식비 / 교통 / 의료 / 생활용품 / 여가 / 경조사 / 반려동물 / 학원비 / 구독료 / 기타 중에서 고르게 해줘. 글씨는 크게, 사용법은 쉽게 부탁해. 그리고 기존 지출내역을 담은 엑셀 파일을 올려서 목록을 채울 수 있게 해줘. 엑셀 칸 순서는 날짜 / 내용 / 카테고리 / 결제수단 / 금액 이고, 첫 줄 제목칸과 맨 아래 '합계' 줄은 목록에 들어가지 않게 해줘. 목록에서 한 줄씩 지울 수 있는 삭제 단추도 넣어줘. 저장은 내려받아 열었을 때 되게 하고, 클로드 미리보기 화면에서는 경고 대신 '내려받아 열면 저장됩니다' 라고만 알려줘. 화면은 아래와 같이 만들어줘. - 맨 위에 큰 제목 '간단 가계부', 그 아래 작은 안내문 한 줄 - 배경은 연한 베이지색, 각 부분은 흰색 둥근 상자로 나눠줘 - 상자는 위에서부터 ① 새 지출 입력 ② 엑셀 파일로 불러오기 ③ 지출 목록 ④ 카테고리별 합계 순서로 - 지출 목록은 날짜 / 내용 / 카테고리 / 결제수단 / 금액 5칸짜리 표로, 금액은 오른쪽에 붙여서 - 카테고리별 합계는 작은 네모 칸들을 바둑판처럼 늘어놓고, 맨 아래 전체 합계는 주황색 큰 상자에 흰 글씨로 크게 - 포인트 색은 주황색 한 가지만 쓰고, 글씨는 크게, 단추와 입력칸도 누르기 쉽게 크게 - 금액은 12,000원 처럼 쉼표와 '원'을 붙여서 보여줘

왜 이 문장들이 꼭 필요한가 — ① “아티팩트로” 라고 해야 화면 오른쪽에 실제로 쓰는 앱이 뜹니다. ② 카테고리 10개를 다시 적어야 새 대화에서도 ①번에서 정한 칸으로 나옵니다. ③ “HTML 파일 하나짜리” 를 빠뜨리면 .jsx 파일로 만들어집니다 — .jsx는 크롬에서 더블클릭해도 열리지 않아 오늘 마지막 단계(다운로드 → 북마크)를 못 합니다. ④ “첫 줄 제목칸과 합계 줄은 빼고” 를 빠뜨리면 엑셀을 올렸을 때 ‘날짜·합계’ 라는 이상한 줄이 목록에 섞입니다. ⑤ 화면 구성까지 적어야 수강생 화면이 제각각으로 나오지 않습니다 — 색·순서를 안 적으면 사람마다 전혀 다른 앱이 나와서 같이 진도를 맞추기 어렵습니다.

완성 화면은 이렇게 나옵니다 — 이 모양이면 성공

프롬프트 7 — 세 가지 한꺼번에모두 함께
방금 만든 가계부 앱에 아래 기능을 추가해줘. 화면 구성과 색, HTML 파일 하나인 것도 그대로 두고 기능만 더해줘. 1. 기록을 엑셀 파일로 내려받아 보관 — 올리기 · 내려받기 모두 엑셀로 2. 카드 / 현금 / 계좌이체 같은 결제수단도 구분해서 입력하고 목록에서도 구분되어 보이게 3. 내려받아 크롬으로 열었을 때 다시 열어도 입력한 내용이 그대로 남아있게, 저장됐는지 화면에서 확인할 수 있게. 클로드 미리보기 화면에서는 저장이 막혀 있으니 그때는 경고 대신 '내려받아 열면 저장됩니다' 라고만 알려줘

※ “화면 구성과 색은 그대로 두고” 를 꼭 넣으세요 — 이 말이 없으면 기능을 더하면서 앱 모양이 통째로 바뀌어 버립니다. 2번은 ⑤에서 이미 됐다면 그대로 두고 넘어갑니다.

  • 중간에 멈추면 → “이어서 계속 만들어줘”
