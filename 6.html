5분

오늘은 무료 계정으로 앱을 다섯 번에 걸쳐 키웁니다. 요청 한 번이 곧 자원입니다.

  1. 새 대화를 열지 마세요. 열면 앱을 처음부터 다시 만들어야 합니다. 오늘은 대화창 하나로 끝까지 갑니다.
  2. 안 될 때 "다시 만들어줘"는 금지입니다. → "○○ 부분만 고쳐줘" 라고 하세요.
  3. 화면 사진을 올려 물어보지 마세요. 사진은 소모가 큽니다. 무슨 일이 생겼는지 말로 적으세요.
  4. 초록색 저장 표시가 나오면 무조건 [다운로드]. 되돌아갈 자리를 만들어 두는 겁니다.
  5. 막히면 그 자리에서 강사 완성본을 받아 다음 단계로 합류하세요. 하는 일은 똑같습니다.

강사 완성본 열어 보기 강사 완성본 내려받기

막혔을 때 쓰는 비상용입니다. 내려받으면 PDF편집기.html 이라는 파일이 생기고, 더블클릭하면 크롬에서 바로 열립니다. 제목을 눌러 내 이름으로 바꿀 수 있습니다.

한도에 걸렸거나 "대화가 너무 깁니다"가 떠도 끝이 아닙니다. 받아 둔 .html 파일을 새 대화에 올려서 "이 파일에 ○○ 기능을 추가해줘" 하면 그대로 이어집니다. 집에서 복습할 때도 이 방법을 씁니다.

오늘 쓸 파일은 이 하나에 다 들어 있습니다. 수업 시작할 때 먼저 받아 두세요.

프롬프트 1 — 복사한 뒤 이름부터 내 이름으로 고치세요
PDF를 다루는 웹앱을 아티팩트로 만들어줘. 제목은 강지애의 PDF 편집기 라고 해줘. 기능은 세 가지야. 아래 순서대로 만들어줘. 컴퓨터에 있는 PDF 파일을 화면 위로 끌어다 놓으면 올라가게 해줘. 여러 개를 한꺼번에 놓아도 되게 해줘. 올린 PDF의 페이지를 그림으로 죽 늘어놓아 보여줘. 페이지마다 번호를 붙여줘. 파일별로 칸을 나누지 말고, 모든 파일의 페이지를 하나의 목록에 이어서 나란히 늘어놓아 줘. 번호도 파일마다 1번부터 다시 세지 말고, 전체를 통틀어 1번부터 차례로 붙여줘. 어느 파일에서 온 페이지인지는 그림 아래에 작은 글씨로만 적어줘. 페이지를 손으로 끌어다 놓으면 순서가 바뀌게 해줘. 서로 다른 파일에서 온 페이지끼리도 순서를 바꿀 수 있어야 해. 예를 들어 두 번째 파일의 1페이지를 첫 번째 파일의 1페이지 앞으로 옮길 수 있어야 해. 파일 안에서만 순서가 바뀌면 안 돼. 끌기가 어려운 사람을 위해서, 페이지마다 앞으로 보내기 단추와 뒤로 보내기 단추도 같이 넣어줘. 페이지마다 빼기 단추를 넣어줘. 잘못 눌렀을 때 쓸 되돌리기 단추도 하나 넣어줘. 화면에 있는 페이지를 전부 하나로 합쳐서 PDF 한 개로 저장하게 해줘. 저장하기 전에 파일 이름을 내가 직접 적을 수 있게 해줘. 글씨는 크게 하고, 단추에는 무슨 일이 일어나는지 한글로 적어줘.

프롬프트 2 — 같은 대화창에 이어서

  • 03 영수증 거꾸로를 올려 두 페이지를 바로 세우기 — 돌리기를 두 번 누르면 됩니다

"미리보기는 돌아가는데 저장한 파일은 그대로야. 저장할 때도 돌아가게 고쳐줘."

PDF를 그림으로

4단계10분

카톡이나 문자로 보낼 때 PDF는 열기가 번거롭습니다. 그림으로 바꾸면 바로 보입니다.

프롬프트 4
페이지를 그림 파일로 뽑는 기능을 더해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. 페이지마다 작은 체크 칸을 만들어줘. 체크한 페이지를 그림으로 저장 이라는 단추를 넣어줘. 그림 파일 이름도 내가 직접 적을 수 있게 해줘. 두 장 이상 체크했으면 하나의 압축 파일로 묶어서 받아지게 해줘.
압축 파일이 안 만들어졌을 때만 — 이어서 추가로 보내세요
여러 장을 하나의 압축 파일로 묶는 게 안 돼. JSZip 을 cdnjs 에서 불러와서 고쳐줘.

여러 장이 따로따로 떨어져 내려오면 그때만 보내세요. 8단계에서도 똑같이 쓸 수 있습니다.

  • 두 페이지 이상 체크해 압축 파일 한 개로 받아지는지 확인

이제 양쪽으로 다 됩니다. 사진에서 PDF로 가는 길은 제출용, PDF에서 그림으로 가는 길은 전송용입니다.

  • 09 안내책자 8페이지를 올려 4개로 나누기 → 2페이지씩 네 개가 나옵니다
  • 파일 이름을 안내책자 로 적고 저장 → 압축을 풀어 확인
  • 3개로도 나눠 보기 → 3페이지 · 3페이지 · 2페이지 로 나뉩니다. 앞의 파일부터 한 페이지씩 더 갑니다

파일이 하나씩 따로 떨어지면 크롬이 "파일 여러 개 다운로드" 팝업으로 막습니다. 그래서 압축 파일 한 개로 묶어 달라고 부탁하는 것입니다.

실전 미션 세 가지

15분

이제 만든 앱으로 진짜 일을 시켜 봅니다. 하나씩 끝낼 때마다 손을 드세요.

※ 시간이 모자라면 미션 A 하나만 하고 넘어가세요. 나머지는 집에서 해도 됩니다.

미션에 쓰는 파일은 맨 처음 받은 압축 폴더 안에 다 있습니다. 아직 안 받으셨다면 여기서 받으세요.

미션 A · 관공서에 낼 서류 04 계약서 앞장과 05 뒷장을 합치고, 그 뒤에 06 관리비고지서 사진을 붙여 한 파일로 저장
→ 모두 3페이지가 나오면 성공. 내 사진이 있으면 그것으로 해도 됩니다
미션 B · 보험사에 낼 영수증 03 영수증 거꾸로의 두 페이지를 바로 세워서 저장
→ 저장한 파일을 열었을 때 글자가 똑바로 읽히면 성공
미션 C · 모임에 나눠 줄 자료 07 안내문 광고포함에서 광고 페이지를 빼고, 08 동창회자료 순서뒤바뀜을 1 · 2 · 3 순서로 맞춘 뒤 둘을 합쳐 2개로 나눠 저장
→ 합치면 5페이지, 2개로 나누면 3페이지 + 2페이지가 됩니다

정답은 종이에 적혀 있습니다. 동창회 자료에는 페이지마다 큰 숫자가, 안내문에는 광고 페이지에 "광 고" 라고 크게 적혀 있습니다. 헷갈리면 숫자만 보세요.

  • 미션마다 저장한 파일을 열어서 눈으로 확인했다
  • 세 개 다 했으면 내 서류로 한 번 더 해 봤다

미션이 안 풀리면 기능이 덜 붙은 것입니다. 해당 단계로 돌아가 그 프롬프트를 다시 보내세요.

크롬 북마크로 앉히기

5분

오늘 만든 앱을 언제든 한 번에 열리게 만듭니다. 순서를 꼭 지키세요.

  1. 「문서」 폴더 안에 「내앱」 폴더를 새로 만듭니다
  2. 내려받은 최종본 .html 파일을 그 폴더로 옮깁니다 — 순서가 중요합니다
  3. 옮긴 파일을 더블클릭 → 크롬에서 열립니다
  4. 주소창 오른쪽 별표를 눌러 이름을 내 PDF 편집기 로 저장
  5. 이제 북마크만 누르면 언제든 실행됩니다

꼭 지킬 것 세 가지
첫째, 인터넷이 연결돼 있어야 열립니다 — PDF를 다루는 부품을 인터넷에서 받아 쓰기 때문입니다
둘째, 파일을 옮기거나 지우면 북마크가 깨집니다 — 다운로드 폴더에 두면 나중에 정리하다 날립니다. 그래서 먼저 옮기고 북마크합니다
셋째, PC 크롬 기준입니다 — 스마트폰에서는 이 방법이 안 됩니다

아티팩트(claude.ai 화면)를 북마크하는 건 권하지 않습니다. 로그인이 필요하고 대화가 밀리면 찾기 어렵습니다.

완성본 새 창으로 열기 완성본 내려받기

오늘 만든 것이 잘 안 되면 이 완성본을 받아 그대로 쓰세요. 하는 일은 똑같습니다. 제목을 누르면 내 이름으로 바꿀 수 있습니다.

집에서 이어 하기

복습

여기부터는 집에서 합니다. 무료 계정은 몇 시간 지나면 다시 쓸 수 있습니다. 수업에서 못 끝낸 단계가 있어도 똑같은 방법으로 이어 가면 됩니다.

딱 하나만 챙기면 됩니다 — 내려받아 둔 .html 파일. 이 파일이 오늘 만든 앱 그 자체입니다. 이것만 있으면 처음부터 다시 만들 필요가 없습니다.

  1. claude.ai 에서 새 대화를 엽니다
  2. 마지막으로 받아 둔 .html 파일을 올립니다 (클립 단추 → 파일 선택)
  3. 아래 문장을 붙여넣고, 그 아래에 못 끝낸 단계의 프롬프트를 이어 붙입니다
이어 하기 — 파일을 올린 뒤에 붙여넣기
올린 html 파일은 내가 만든 PDF 편집기야. 이 파일을 그대로 아티팩트로 열어주고, 아래 기능을 추가해줘. 지금 있는 기능은 하나도 빼지 말고 그대로 둬. 여기에 못 끝낸 단계의 프롬프트를 붙여넣으세요.

이 방법이면 처음부터 다시 만들지 않아도 됩니다. 앞으로 기능을 더 붙이고 싶을 때도 똑같이 하면 됩니다.

  • 혼자 더 붙여 볼 만한 것 — 페이지 번호 찍기 / 홀수 페이지와 짝수 페이지 나누기 / 원하는 페이지 범위만 뽑기
  • 단, 용량 줄이기와 비밀번호 걸기는 잘 안 됩니다. 안 되면 붙들지 말고 넘어가세요
  • PDF 위에 한글 글자를 얹는 것도 글꼴 문제로 잘 깨집니다

기능은 다 끝났습니다. 이제 내 앱 모양을 내 마음에 들게 바꿔 봅니다. 사용량이 돌아온 뒤에 하세요.

※ 건너뛰어도 괜찮습니다. 기능과는 상관없이 모양만 바꾸는 단계입니다.

꾸미기 프롬프트
기능은 그대로 두고 보기만 바꿔줘. 바탕은 따뜻한 베이지색으로, 상자는 크림색으로 해줘. 테두리는 아주 얇은 선 하나만 쓰고, 그림자는 쓰지 마. 중요한 단추는 진한 초록색 바탕에 크림색 글씨로, 알약처럼 둥글게 해줘. 제목은 명조체로, 본문은 고딕체로 해줘. 여백을 넉넉하게 주고, 글씨는 크게 해줘.

색이 마음에 안 들면 "바탕을 연한 하늘색으로 바꿔줘" 처럼 그냥 말로 부탁하세요. 사람마다 결과가 조금씩 다르게 나오는 것이 정상입니다.

다 꾸몄으면 다시 [다운로드] — 이 파일로 북마크를 바꿔 두세요.
