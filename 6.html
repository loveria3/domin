오늘의 규칙 — 사용량 아끼는 법

5분

오늘은 무료 계정으로 앱을 다섯 번에 걸쳐 키웁니다. 요청 한 번이 곧 자원입니다.

  1. 새 대화를 열지 마세요. 열면 앱을 처음부터 다시 만들어야 합니다. 오늘은 대화창 하나로 끝까지 갑니다.
  2. 안 될 때 "다시 만들어줘"는 금지입니다. → "○○ 부분만 고쳐줘" 라고 하세요.
  3. 화면 사진을 올려 물어보지 마세요. 사진은 소모가 큽니다. 무슨 일이 생겼는지 말로 적으세요.
  4. 단계가 끝나면 무조건 [다운로드]. 되돌아갈 수 있는 자리를 만들어 두는 겁니다.
  5. 막히면 그 자리에서 강사 완성본을 받아 다음 단계로 합류하세요. 하는 일은 똑같습니다.

한도에 걸렸거나 "대화가 너무 깁니다"가 떠도 끝이 아닙니다. 받아 둔 .html 파일을 새 대화에 올려서 "이 파일에 ○○ 기능을 추가해줘" 하면 그대로 이어집니다. 집에서 복습할 때도 이 방법을 씁니다.

① 계약서 앞장 ② 계약서 뒷장 ③ 광고 낀 안내문 3쪽 ④ 순서 뒤바뀐 자료 3쪽 ⑤ 거꾸로 된 영수증 2쪽 ⑥ 안내책자 8쪽

여섯 개 모두 미리 내려받아 두세요. 단계마다 하나씩 씁니다.

1

올리고 · 합치고 · 순서 바꾸기

1단계28분

한 번의 요청으로 쓸 수 있는 앱이 나옵니다. 디자인과 이름까지 여기에 다 넣습니다.

프롬프트 1 — 복사한 뒤 [이름]부터 내 이름으로 고치세요
PDF 편집기 웹앱을 아티팩트로 만들어줘. 제목은 [강지애]의 PDF 편집기 로 해줘. 기능은 이렇게 만들어줘. 1. 파일을 화면에 끌어다 놓으면 올라가게. 여러 개를 한꺼번에 놓아도 되게. 2. 올린 PDF의 쪽을 그림으로 죽 늘어놓아 보여주기. 쪽마다 번호를 붙여줘. 3. 쪽을 끌어다 놓으면 순서가 바뀌게. 끌기가 어려울 수 있으니 [◀] [▶] 단추도 같이 넣어줘. 4. 쪽마다 [빼기] 단추. 잘못 눌렀을 때 쓰는 [되돌리기] 단추. 5. 전부 하나로 합쳐서 저장. 저장할 파일 이름을 직접 적을 수 있게 해줘. 화면은 아주 단순하게. 위에 쪽 미리보기, 아래에 단추 한 줄. 글씨는 크게, 단추마다 무슨 일이 일어나는지 한글로 적어줘. 디자인은 이렇게 해줘. 바탕은 베이지 #f4ede2, 상자는 크림색 #fbf6ec, 테두리는 #d9cfbe 얇은 선 하나로만. 글자는 #1b1a18, 설명 글은 #7a716a. 중요한 단추는 진한 초록 #2a3b2e 바탕에 크림색 글씨, 알약처럼 완전히 둥글게. 작은 라벨은 구리색 #b3753a 에 영문 대문자로, 자간은 넓게. 제목은 명조체, 본문은 고딕체. 그림자는 쓰지 말고 여백을 넉넉하게 줘. pdf-lib 과 pdf.js 는 cdnjs 에서 불러오는 방식으로 만들어줘.
  • 내 이름이 제목에 떴는지 먼저 확인 — 내가 만든 앱입니다
  • ① 과 ② 를 한꺼번에 끌어다 놓아 합쳐서 저장
  • ③ 을 올려 광고가 낀 2쪽만 빼기 → 잘못 뺐으면 되돌리기
  • ④ 를 올려 끌어서 1 → 2 → 3 순서로 맞추기
막혔을 때 — 이 세 마디면 됩니다
1번 기능만 먼저 해줘. 화면이 하얗게 나와. 무슨 문제인지 찾아서 고쳐줘. pdf-lib 과 pdf.js 를 cdnjs 에서 불러오는 방식으로 다시 만들어줘.
저장 ① — 아티팩트 오른쪽 위 [다운로드]를 눌러 .html 파일로 받아 두세요. 여기가 첫 번째 되돌아갈 자리입니다.
2

돌리기

2단계8분

스캔하면 꼭 한두 쪽이 거꾸로 들어갑니다. 관공서에 낼 서류라면 반드시 세워야 합니다.

프롬프트 2 — 같은 대화창에 이어서
쪽마다 [↻ 돌리기] 단추를 추가해줘. 누를 때마다 90도씩 돌아가고, 미리보기 그림도 같이 돌아가게. 저장할 때 돌린 그대로 저장되게 해줘. 앞에서 만든 기능은 그대로 두고 이것만 더해줘.
  • ⑤ 거꾸로 된 영수증을 올려 2쪽을 바로 세우기 — ↻ 를 두 번 누르면 됩니다
  • 저장한 파일을 열어서 눈으로 확인 — 미리보기만 돌고 저장은 안 돌아가는 일이 흔합니다
저장 ② — 다시 [다운로드]. 앞 파일은 지우지 말고 그대로 두세요.
3

사진을 PDF로

3단계10분

스마트폰으로 찍은 서류를 그대로 제출용 PDF로 바꿉니다. 오늘 배우는 것 중 실제로 제일 많이 쓰게 될 기능입니다.

프롬프트 3
사진(JPG · PNG)을 끌어다 놓으면 PDF 한 쪽으로 들어가게 해줘. 사진은 A4 크기 한 쪽 가운데에 비율 그대로 들어가면 돼. 사진도 순서 바꾸기 · 빼기 · 돌리기가 똑같이 되게 해줘. 앞에서 만든 기능은 그대로 두고 이것만 더해줘.
  • 스마트폰으로 아무 종이나 찍어 카톡 나에게 보내기 → 컴퓨터에서 내려받아 올리기
  • 사진이 없으면 5차시 영수증 샘플이나 6차시 예약증 샘플을 써도 됩니다
  • ①② 뒤에 내 사진 한 장을 붙여 한 파일로 저장해 보기
저장 ③ — [다운로드].
4

PDF를 그림으로

4단계10분

카톡·문자로 보낼 때 PDF는 열기 번거롭습니다. 그림으로 바꾸면 바로 보입니다.

프롬프트 4
쪽마다 체크 칸을 만들고, [체크한 쪽을 그림으로 저장] 단추를 추가해줘. PNG로 저장되고, 저장할 파일 이름을 직접 적을 수 있게 해줘. 여러 장이면 ZIP 한 개로 묶어서 받게 해줘. JSZip 은 cdnjs 에서 불러오면 돼. 앞에서 만든 기능은 그대로 두고 이것만 더해줘.
  • ③ 안내문에서 1쪽만 체크해 그림으로 저장 → 단톡방에 올려 보기
  • 두 쪽 이상 체크해 ZIP으로 받아지는지 확인

PDF ↔ 그림이 이제 양쪽으로 됩니다. 사진 → PDF는 제출용, PDF → 그림은 전송용입니다.

저장 ④ — [다운로드].
5

균등하게 나누기

5단계10분

긴 자료를 여러 사람에게 나눠 줄 때 씁니다. 여기까지 오면 앱이 완성입니다.

프롬프트 5
[균등하게 나눠서 저장] 기능을 추가해줘. 몇 개로 나눌지 숫자로 정하고, 쪽수가 딱 안 나눠지면 앞쪽부터 한 쪽씩 더 가게 해줘. 파일 이름을 직접 적으면 계약서_1.pdf, 계약서_2.pdf 처럼 번호가 붙고, 전부 ZIP 한 개로 묶여서 받아지게 해줘. 나누기 전에 "8쪽 → 3개 파일" 처럼 결과를 미리 알려주면 좋겠어. 앞에서 만든 기능은 그대로 두고 이것만 더해줘.
  • ⑥ 안내책자 8쪽을 올려 4개로 나누기 → 2쪽씩 네 개가 나옵니다
  • 파일 이름을 [안내책자] 로 바꿔 저장 → ZIP을 풀어 확인
  • 3개로도 나눠 보기 → 3·3·2 처럼 앞쪽부터 한 쪽씩 더 갑니다

파일이 하나씩 따로 떨어지면 크롬이 "파일 여러 개 다운로드" 팝업으로 막습니다. 그래서 ZIP 한 개로 묶으라고 부탁하는 것입니다.

저장 ⑤ — 최종본 — [다운로드]. 이 파일이 오늘의 결과물입니다.
6

실전 미션 세 가지

여유 시간

이제 만든 앱으로 진짜 일을 시켜 봅니다. 하나씩 끝낼 때마다 손을 드세요.

미션 A · 관공서에 낼 서류①②를 합치고 뒤에 내 사진 1장을 붙여 한 파일로 저장
미션 B · 보험사에 낼 영수증⑤의 2쪽을 바로 세워서 두 쪽 모두 담아 저장
미션 C · 모임에 나눠 줄 자료③에서 광고를 빼고 ④의 순서를 맞춰 합친 뒤, 2개로 나눠 ZIP으로 저장
  • 미션마다 저장한 파일을 열어서 눈으로 확인했다
  • 세 개 다 했으면 내 서류로 한 번 더 해 봤다

미션이 안 풀리면 기능이 덜 붙은 것입니다. 해당 단계로 돌아가 다시 요청하세요.

7

크롬 북마크로 앉히기

5분

오늘 만든 앱을 언제든 한 번에 열리게 만듭니다. 순서를 꼭 지키세요.

  1. 「문서」 폴더 안에 「내앱」 폴더를 새로 만듭니다
  2. 내려받은 최종본 .html 파일을 그 폴더로 옮깁니다 — 순서가 중요합니다
  3. 옮긴 파일을 더블클릭 → 크롬에서 열립니다
  4. 주소창 오른쪽 ★ 을 눌러 이름을 [내 PDF 편집기] 로 저장
  5. 이제 북마크만 누르면 언제든 실행됩니다

꼭 지킬 것 세 가지
① 인터넷이 연결돼 있어야 열립니다 — PDF를 다루는 부품을 인터넷에서 받아 쓰기 때문입니다
② 파일을 옮기거나 지우면 북마크가 깨집니다 — 다운로드 폴더에 두면 나중에 정리하다 날립니다. 그래서 먼저 옮기고 북마크합니다
③ PC 크롬 기준입니다 — 스마트폰에서는 이 방법이 안 됩니다

아티팩트(claude.ai 화면)를 북마크하는 건 권하지 않습니다. 로그인이 필요하고 대화가 밀리면 찾기 어렵습니다.

강사 완성본 내려받기

오늘 만든 것이 잘 안 되면 이 완성본을 받아 그대로 쓰세요. 하는 일은 똑같습니다. 제목을 누르면 내 이름으로 바꿀 수 있습니다.

＋

집에서 이어 하기

복습

수업 중에 사용량이 끊겼거나 못 끝낸 단계가 있으면 집에서 이어 하세요. 몇 시간 지나면 다시 쓸 수 있습니다.

  1. claude.ai 에서 새 대화를 엽니다
  2. 마지막으로 받아 둔 .html 파일을 올립니다 (클립 단추 → 파일 선택)
  3. 아래 문장을 붙여넣습니다
이어 하기 — 파일을 올린 뒤에 붙여넣기
올린 html 파일은 내가 만든 PDF 편집기야. 이 파일을 그대로 아티팩트로 열어주고, 아래 기능을 추가해줘. 지금 있는 기능은 하나도 빼지 말고 그대로 둬. (여기에 못 끝낸 단계의 프롬프트를 붙여넣으세요)

이 방법이면 처음부터 다시 만들지 않아도 됩니다. 앞으로 기능을 더 붙이고 싶을 때도 똑같이 하면 됩니다.

  • 혼자 더 붙여 볼 만한 것 — 쪽 번호 찍기 / 홀수·짝수 쪽 나누기 / 원하는 쪽 범위만 뽑기
  • 단, 용량 줄이기(압축)와 비밀번호 걸기는 잘 안 됩니다. 안 되면 붙들지 말고 넘어가세요
  • PDF 위에 한글 글자를 얹는 것도 글꼴 문제로 잘 깨집니다

도전 — 쪽 번호 찍기
쪽 아래 가운데에 쪽 번호를 찍어 주는 기능을 추가해줘. 숫자만 찍으면 되니까 한글 글꼴은 필요 없어. 켜고 끌 수 있게 하고, 저장할 때만 찍히게 해줘.
  • 왼쪽 메뉴 '프로젝트' → 새 프로젝트 [내 생활 AI] 를 만들어 6주 자료 모아 두기
  • 짝꿍이 만든 앱과 바꿔서 같은 미션 해 보기 — 어디가 다른지 보입니다

1. 앱은 한 번에 안 만든다 — 기능 하나씩 붙인다

2. 단계가 끝나면 무조건 다운로드 — 되돌아갈 자리를 만든다

3. 안 될 때는 "다시 만들어줘"가 아니라 "○○만 고쳐줘"

4. 한도에 걸려도 끝이 아니다 — 받아 둔 파일을 올려서 이어 간다

5. 완성본은 「문서」로 옮긴 뒤 크롬 북마크
