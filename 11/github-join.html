깃허브(GitHub) 가입하고 올리기

① 가입하기(약 10분)로 계정을 만들고, ② 올리기(배포)(약 10분)로 5차시 운동일기를 인터넷 주소로 엽니다. 그림이 저절로 넘어가며 주황 동그라미가 누를 곳, 주황 네모가 볼 곳, 회색 네모는 누르지 않는 곳이에요.

시작 전에 준비할 것

  1. 컴퓨터의 크롬 — 가입·올리기는 휴대폰보다 컴퓨터가 쉬워요
  2. 지금 열어 볼 수 있는 구글 메일 — 확인 숫자가 이 메일로 와요
  3. 쓸 아이디를 미리 정하기 — 영어 소문자, 예: jiae-domin (내 주소 앞부분이 됨)
  4. 올릴 때는 5차시에 만든 운동일기 폴더 — 파일 5개(index.html · manifest.webmanifest · sw.js · icon-192.png · icon-512.png)

💡 천천히 보려면 ⏸ 멈춤을 누르고 다음 ▶으로 한 장씩 넘기세요. 가입이 끝나면 저절로 ② 올리기로 이어집니다.

한눈에 보는 순서

① 가입하기

github.com→Sign up→이메일 · 비밀번호 · 아이디 · 나라→그림 문제→메일 숫자 8자리→로그인

② 올리기(배포)

New→jiae-fit · Public→uploading an existing file→파일 5개→Commit changes→Settings → Pages→main · / (root) · Save→1~2분 뒤 내 주소

막히면 여기를 보세요

① 가입할 때

⚠ Username 아래에 빨간 글씨가 나와요 누가 이미 쓰는 아이디예요. 뒤에 숫자나 하이픈(-)을 붙여 보세요. 예: jiae-domin → jiae-domin2, jiae-jeju. 한글 · 띄어쓰기 · 밑줄(_)은 못 써요.
⚠ 비밀번호를 넣었는데 넘어가지 않아요 15자 이상이거나, 숫자와 영어 소문자가 들어간 8자 이상이어야 해요. 이름 + 생일처럼 남이 알기 쉬운 것은 피하세요.
⚠ 메일이 안 와요 ① 구글 메일의 스팸함 · 프로모션 탭을 보세요. ② 가입 화면의 Resend the code를 누르면 다시 와요. ③ 이메일 주소를 잘못 쓴 것 같으면 처음부터 다시 가입합니다.
⚠ 그림 문제가 계속 나와요 정상이에요. 천천히 다시 풀면 됩니다. 안 되면 새로고침(F5)하고 처음부터 다시 해 보세요.
💡 Continue with Google 단추는요? 구글 계정으로 바로 가입하는 단추예요. 써도 되지만 뒤 화면이 이 안내와 조금 달라요. 수업에서는 모두 같은 화면을 보도록 이메일로 가입합니다.
💡 나중에 2단계 인증(2FA) 안내가 와요 가입하고 얼마 뒤 2단계 인증을 켜라는 안내가 올 수 있어요. 휴대폰 인증 앱이나 패스키로 설정합니다. 막히면 강사와 함께 해요.

② 올릴 때

⚠ 404 — File not found 가 떠요 ① Save 하고 1~2분이 안 지났어요 — 기다렸다 새로고침. ② 저장소 위쪽 Actions 탭 맨 위에 초록 체크가 있는지 보세요. 노란 점이면 아직 반영 중이에요. ③ 파일 이름이 정확히 index.html(소문자)인지 확인하세요.
⚠ 주소 끝에 /운동일기/ 를 붙여야 열려요 폴더째 끌어다 놓아서 그래요. 저장소에서 폴더를 지우고, 폴더를 열어 안의 파일 5개만 다시 올리세요.
⚠ Pages 메뉴에 Branch 고르는 칸이 없어요 저장소가 Private이면 무료 계정은 Pages를 못 씁니다. Settings → General 맨 아래 Change visibility → Public.
⚠ 휴대폰에 「홈 화면에 설치」가 안 보여요 컴퓨터 파일(더블클릭)이 아니라 github.io 주소로 열어야 설치돼요. manifest.webmanifest · sw.js · 아이콘 2개까지 5개 모두 올라갔는지 저장소에서 확인하세요.
💰 돈이 드나요? 아니요. 무료(Free)로 가입하고, 웹페이지 올리기(GitHub Pages)도 무료예요. 결제 · Pro · 카드 입력 화면이 나오면 누르지 말고 강사에게 물어보세요.

✓ 다 끝나면 적어 두기

아이디예: jiae-domin 가입 메일예: jiae.domin@gmail.com 저장소예: jiae-fit 내 앱 주소jiae-domin.github.io/jiae-fit

비밀번호는 종이 대신 크롬 비밀번호 저장이나 휴대폰 잠금 메모에 남겨 두세요. 앱 주소는 카톡 나와의 채팅으로 보내 두면 언제든 찾을 수 있어요.

⚠ 깃허브에 올린 자료는 주소를 아는 누구나 볼 수 있어요. 전화번호 · 집 주소 같은 개인정보는 올리지 마세요.
