오늘 일하는 순서

원하는 대로 될 때까지 3 ↔ 4를 돕니다

프롬프트 1 — 판정만 받기
AI교육 소식을 매일 아침 찾아 주는 웹앱을 만들려고 해. 보여 줄 것 · 남길 것 · 누가 볼지 · 저절로 할 일 · 올릴 곳에 대한 내 답은 위 표와 같아. 홀(화면) · 주방(서버) · 창고(데이터베이스) 중 무엇이 필요한지, 각각 무엇으로 하면 좋을지 표로 보여줘. 아직 만들지 마.
홀 = index.html (버셀) · 주방 = 구글 앱스크립트 (단추 주문 + 매일 7시 트리거) · 창고 = 구글 시트 (키워드 탭 · 검색함 탭)

다섯 질문은 위니브 『바이브 코딩 에센셜』 9.5절의 판단 질문과 브리프 형식을 합친 것입니다. "② 무엇을 남길지 · ③ 누가 볼지, 이 두 가지는 클로드가 조용히 정하게 두지 않는다"를 강조하세요.

칠판(화면)에 다섯 질문을 띄워 두고 단계마다 "지금은 몇 번 질문을 하고 있죠?"라고 물으면 수업의 뼈대가 잡힙니다.

오늘은 강사가 검증한 틀을 쓰므로 클로드에게 처음부터 만들게 하지 않습니다. 이 프롬프트는 '판정 연습'이고, 집에서 다른 주제로 만들 때 그대로 쓰는 순서라고 안내합니다.

3

내 키워드 정하기

④ 저절로 할 일코워크6분

코워크 폴더: 내작업실/검색함을 만들고, 받은 두 파일(index.html · 검색함-코드.txt)을 넣은 뒤 폴더를 연결합니다.

프롬프트 3-1 — 클로드가 먼저 묻게
매일 아침 AI교육 소식을 찾아 주는 검색함을 만들 거야. 나에게 질문 세 개를 해서, 구글 뉴스에 넣을 검색 키워드 5개와 꼭 들어갈 말, 빼는 말을 정해 키워드.txt로 저장해줘.
Q1. 어느 지역 교육을 찾으세요? (예: 제주 전체 / 서귀포) Q2. 누구를 위한 교육이 궁금하세요? (시니어 · 소상공인 · 교사 …) Q3. 빼고 싶은 기사는? (AI 주식 · 대학 입시 …)
프롬프트 3-2 — 코드에 채우기
검색함-코드.txt 맨 위 DEFAULT_KEYWORDS · DEFAULT_MUST · DEFAULT_DROP을 키워드.txt 내용으로 바꿔줘. 다른 곳은 고치지 마.

규칙 더 보기

코드의 WINDOW_DAYS(최근 며칠) · MAX_PER_KW(키워드당 몇 건)를 내 쓰임에 맞게 바꿔 달라고 해 보세요. 숫자만 바꾸는 일이라 안전합니다.

4

주방 차리기 — 구글 시트 + 앱스크립트

② 남길 것 · ③ 누가 볼까 · ④핵심20분

5차시 운동일기와 같은 순서입니다. 한 칸씩 같이 해요.

프롬프트 4 — 붙여 넣기 전에 설명부터
검색함-코드.txt가 무엇을 하는지 쉬운 말로 다섯 줄로 설명해줘. 내 구글 계정에서 무엇을 읽고 쓰는지, 다른 곳으로 보내는 것이 있는지도 알려줘. 고치지는 마.
① 시트 만들기sheets.new → 이름을 키워드 검색함으로
② 코드 넣기메뉴 확장 프로그램 → Apps Script → 안의 글을 모두 지우고 검색함-코드.txt 내용 붙여 넣기 → 저장(Ctrl+S)
③ PIN 금고왼쪽 ⚙ 프로젝트 설정 → 맨 아래 스크립트 속성 → 속성 추가 — 속성 PIN, 값 숫자 4자리 → 저장
④ 첫 실행위쪽 함수 칸에서 setup → ▶ 실행 → 권한 검토 → 내 계정 → 고급 → (프로젝트)로 이동 → 허용
⑤ 주소 받기오른쪽 위 배포 → 새 배포 → ⚙ 웹 앱 · 실행: 나 · 액세스: 모든 사용자 → 배포 → 웹 앱 URL 복사 → 메모장에 붙여 두기
  • 시트 아래에 키워드 · 검색함 탭이 생겼다
  • 검색함 탭에 기사 줄이 몇 개 들어왔다 (0개여도 괜찮아요 — 5번에서 다시 검색)
  • 메모장에 https://script.google.com/macros/s/…/exec 주소가 있다

⚠ ④에서 '확인되지 않은 앱'이 나오는 건 정상입니다 — 내가 만든 앱이라 구글이 심사하지 않았다는 뜻. 프롬프트 4로 무엇을 하는 코드인지 먼저 확인했으니 허용합니다.

🆘 막혔다면 — 강사 공용 주소 [강사 공용 웹 앱 URL] · PIN [수업 때 알려 드림]으로 5번부터 먼저 따라오세요. 내 주방은 쉬는 시간이나 집에서 이 표대로 다시 차리면 됩니다.

가장 많이 막히는 곳: ② 기존 글(function myFunction)을 안 지움 · ③ PIN 속성 이름을 소문자 pin으로 씀 · ④ 다른 함수를 골라 실행 · ⑤ 액세스를 '나만'으로 둠. 돌면서 이 네 가지만 보세요.

강사 공용 주소는 수업 전에 강사 계정으로 같은 코드를 배포해 두고, 수업이 끝나면 배포를 보관(중지)하세요. 공용 시트에는 여럿이 보관한 것이 섞인다는 점도 미리 말해 둡니다.

에러가 없다고 끝이 아닙니다. 내가 원하는 대로인지 직접 써 봅니다. (1번 순서도의 4)

  1. 🆕 새로 탭에서 쓸 만한 것은 ⭐ 보관, 아닌 것은 버림
  2. 버린 기사들에 공통으로 든 말 찾기 → ⚙ 키워드 탭 🚫 빼는 말에 추가 → 💾 키워드 저장
  3. 🔍 지금 검색을 다시 → 잡음이 줄었는지 보기

확인 세 가지

  • 남는가 — 창을 닫았다 다시 열어도 보관함이 그대로
  • 창고에 들어갔는가 — 구글 시트 검색함 탭에서 그 줄의 상태가 보관으로 바뀌었는지 (9번에서 올리면 휴대폰에서도 같은 보관함)
  • 막히는가 — PIN을 일부러 틀리게 넣으면 들어가지 못함

세 가지 확인은 위니브 교재가 서버 있는 앱을 만든 뒤 보라고 권하는 항목(저장되는가 · 잘못된 입력 · 남의 것이 보이는가)을 우리 앱에 맞게 바꾼 것입니다.

"잡음이 많으면 빼는 말 추가"는 이론 ② 5번 순서도의 되돌아가는 선입니다. 화면을 다시 보여 주세요.
