3차시 · 도움말

깃허브(GitHub Pages)로 내 주소 받기

가입하고 → 저장소를 만들어 파일을 올리고 → Pages를 켜면 내아이디.github.io/저장소이름 주소가 생깁니다. 화면이 저절로 넘어가요. 버셀 대신 고를 수 있는 방법입니다. 버셀 따라 하기 →

📄 index.html

막히면 여기를 보세요

⚠ 404 — File not found 가 떠요 ① Save 하고 1~2분이 안 지났어요 — 기다렸다 새로고침. ② 저장소 위쪽 Actions 탭의 맨 위 'pages build and deployment'에 초록 체크가 있는지 보세요. 빨간 ✕나 노란 점이면 아직 반영 전입니다. ③ 파일 이름이 정확히 index.html(소문자)인지 확인하세요.
⚠ 주소 끝에 /올레안내/ 를 붙여야 열려요 폴더째 끌어다 놓아서 그래요. 폴더를 열고 안의 파일만 올리면 내아이디.github.io/halla-olle/로 바로 열립니다. 한글 폴더 이름은 주소에 넣지 않는 게 좋아요.
⚠ Pages 메뉴에 Branch 고르는 칸이 없어요 저장소가 Private이면 무료 계정은 Pages를 못 씁니다. Settings → General 맨 아래 Change visibility → Public.
💡 아이디(Username) = 주소 앞부분 jiae-domin으로 가입하면 주소는 jiae-domin.github.io/저장소이름. 영어 소문자로 짧게 지으세요. 나중에 바꾸면 주소도 바뀌어 QR을 다시 만들어야 해요.
💡 2단계 인증 안내가 와요 가입하고 얼마 뒤 2단계 인증(2FA)을 켜라는 안내가 올 수 있어요. 휴대폰 인증 앱이나 패스키로 설정합니다. 수업에서 막히면 강사와 함께 합니다.
📋 버셀과 무엇이 다른가요? 버셀 — 구글로 가입, 폴더째 끌어다 놓으면 몇 초 만에 주소. 깃허브 — 가입 단계가 조금 더 많고 반영까지 1~2분, 대신 파일이 저장소에 차곡차곡 남고 회사·학교에서 많이 씁니다. 이 교안도 깃허브로 올렸어요. 둘 다 같은 곳에 다시 올리면 주소(QR) 그대로입니다.
✏ 고친 파일을 다시 올리려면 같은 저장소 → Add file → Upload files → 고친 index.html → Commit changes. 새 저장소를 만들면 새 주소가 생겨 QR이 안 맞아요.

✓ 마지막 확인

내 주소를 카톡 나와의 채팅으로 보내고 폰에서 눌러 보세요. 로그인 없이 안내 페이지가 보이면 성공! 4차시 보관함도 새 저장소(예: jiae-prompts)를 만들어 같은 순서로 올립니다.

⚠ 올린 자료는 주소를 아는 누구나 볼 수 있어요. 전화번호·집 주소 같은 개인정보는 넣지 마세요.
