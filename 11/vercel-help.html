3차시 · 도움말

버셀(Vercel)로 내 주소 받기

구글로 가입하고 → index.html을 끌어다 놓으면 → ○○○.vercel.app 주소가 생깁니다. 화면이 저절로 넘어가요. 수업에서는 index.html 대신 올레안내 폴더째(4차시는 보관함 폴더째) 끌어다 놓습니다.

📁 올레안내

막히면 여기를 보세요

⚠ "Social Account is not yet connected…" 가 떠요 Log in(로그인)을 눌러서 그래요. 처음이면 가입부터 해야 합니다. 노란 칸의 Sign up?을 누르고 다시 Continue with Google.
⚠ 팀 이름이 안 써지고 Continue가 안 눌려요 한글로 쳐서 그래요. 키보드 한/영 키로 바꾸고 영어로 쓰세요. 예) kim
⚠ Pro / Hobby 고르는 화면 처음엔 Pro(유료 체험)에 체크되어 있어요. 꼭 아래 personal projects · Hobby를 누르세요.
💡 내 주소는 짧은 쪽입니다 프로젝트 화면 Domains 아래 이름.vercel.app이 내 주소예요. 위쪽의 긴 주소(이름-abc123-….vercel.app)는 보내지 마세요.
💡 Project Name = 주소 여기 쓴 이름이 주소 앞부분이 됩니다. 영어 소문자와 - 만 쓰세요. 이미 누가 쓰는 이름이면 뒤에 엉뚱한 단어가 붙어요 (예: test → test-peach-xi-87). 그래도 괜찮아요 — Domains에 보이는 그대로가 내 주소입니다.
📋 내 주소 복사하는 법 ① Domains 아래 주소 옆 ↗를 눌러 내 사이트 열기 → ② 새로 열린 창의 주소창을 한 번 누르기 → ③ Ctrl + C (복사) → ④ 카톡·패들렛에 Ctrl + V (붙여넣기)
주소는 https://○○○.vercel.app 모양이면 맞아요.
✏ 고친 파일을 다시 올리려면 vercel.com 로그인 → 내 프로젝트 화면에 고친 폴더를 아무 데나 끌어다 놓으면 같은 주소로 바뀝니다. vercel.com/drop에 다시 올리면 새 주소가 생겨 QR이 안 맞아요.

✓ 마지막 확인

내 주소를 카톡 나와의 채팅으로 보내고 폰에서 눌러 보세요. 로그인 없이 안내 페이지가 보이면 성공!

⚠ 올린 자료는 주소를 아는 누구나 볼 수 있어요. 전화번호·집 주소 같은 개인정보는 넣지 마세요.
