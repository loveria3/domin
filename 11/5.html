기획부터 — 아직 만들지 마

10분

바로 만들어 달라고 하지 않습니다. 어떤 화면이 몇 개 필요한지 먼저 받아 보고, 내 생각과 맞는지 확인합니다.

  1. 내작업실 안에 운동일기 폴더 만들기
  2. 클로드 데스크톱 코워크에서 내작업실 폴더 연결
프롬프트 1 — 기획만 받기
가족·친구와 함께 쓰는 운동일기 웹앱을 만들고 싶어. 아직 만들지 말고 기획부터 보여줘. - 쓰는 사람: 휴대폰이 서툰 [60대 엄마]도 쓸 수 있게. 글자는 크게, 거의 누르기만 하면 되게 - 식사: 칼로리 계산은 안 해. '식당 1인분 정식', '학교 급식', '일품순두부에서 순두부'처럼 대충 적어도 기록돼 - 운동: 걷기·달리기·수영 같은 종류를 고르고 몇 분 했는지 기록 - 목표: 일주일 운동 목표(분)와 나의 다짐 한 줄 - 공유: 같은 '모임 코드'로 들어온 가족의 기록이 인터넷으로 함께 보이게. 저장소는 내 구글 시트 (회원가입 없이) - 대시보드: 나와 가족의 결과를 움직이는 그래프로 비교 - 디자인: 어른스러운 종이 다이어리(플래너) 느낌 - 깃허브에 올려서 휴대폰에 앱처럼 설치해 쓸 거야 화면을 몇 개로 나눌지, 화면마다 무엇이 들어가는지 표로 정리하고, 만드는 순서를 단계로 나눠줘.
화면은 4개로 나누면 좋겠어요. ① 기록 — 날짜 · 식사 · 운동 · 메모 ② 함께 — 모임 코드 · 오늘의 소식 · 가족별 기록과 박수 ③ 대시보드 — 목표 레이스 · 날짜별 운동 · 쌓인 시간 · 식사 달력 ④ 목표·설정 — 이름 · 주간 목표 · 다짐 · 모임 · 설치 · 초기화 만드는 순서: 식사 기록 → 운동·목표 → 디자인 → 구글 시트 저장소 → 모임 연결 → 대시보드 → 설치·올리기

내 생각과 다른 곳이 있으면 지금 말하세요. 예) "화면은 3개로 줄여줘", "체중 기록도 넣고 싶어"

프롬프트 2 — 첫 화면 만들기
'운동일기' 폴더에 index.html로 운동일기 웹앱을 시작해줘. 이번에는 [기록] 화면의 식사 기록만 만들어. - 처음 열면 '일기장 이름'(예: 지애네 가족 운동일기)과 내 이름만 묻고 시작. 일기장 이름은 맨 위 제목이 돼 - 맨 위에 날짜. ◀ ▶로 어제 것도 적을 수 있게 (내일로는 못 가게) - [+ 식사 기록]을 누르면 아래에서 입력 칸이 올라오게 1) 언제: 아침·점심·저녁·간식 (지금 시각에 맞게 미리 골라 둬) 2) 메뉴 단추: 식당 1인분 정식, 학교 급식, 구내식당, 순두부찌개, 집밥 한 상, 김밥, 국수·면, 샐러드, 빵·커피, 과일, 고기 외식, 술자리 3) 목록에 없으면 직접 적는 칸 (예: 일품순두부에서 순두부) - 자주 먹은 메뉴는 '자주' 표시를 달아 맨 앞에 - 기록은 이 브라우저에 저장해서 새로고침해도 남게 (localStorage). '삭제'로 지울 수 있게 - 글자는 17px 이상, 단추는 손가락으로 누르기 쉽게 크게
운동일기/index.html 을 만들었어요. 처음 열면 일기장 이름과 내 이름을 적고 → 기록 화면이 나와요. [+ 식사 기록] → 점심(자동 선택) → 학교 급식 → 기록하기 기록은 이 브라우저에 저장돼서 새로고침해도 남아요.

  • 점심에 학교 급식, 저녁에 직접 적기로 일품순두부에서 순두부 넣어 보기
  • 새로고침(F5) 해도 기록이 남아 있는지 · ◀ 눌러 어제 것도 적어 보기

메뉴 단추는 내 생활에 맞게 바꾸세요. 예) "메뉴에 '고구마'를 넣고 '술자리'는 빼줘"

프롬프트 3 — 운동 · 목표 더하기
운동일기에 운동 기록과 목표를 더해줘. 이미 만든 식사 기록은 그대로 둬. - [+ 운동 기록]: 걷기·달리기·수영·자전거·등산·근력운동·요가·스트레칭·줄넘기·[배드민턴]·기타 중 하나 누르기 - 몇 분: 10·20·30·40·60·90분 단추 + −/+ 로 5분씩 조절 - 그날의 메모 한 줄 칸 - [목표·설정] 화면: 일기장 이름·내 이름 바꾸기, 일주일 운동 목표(60·100·150·200·300분), 나의 다짐 한 줄 - 기록 화면 위에 '이번 주 운동 ○분 / 목표 ○분' 막대 (월요일부터 계산) - 화면 아래 메뉴 4개: 기록 · 함께 · 대시보드 · 목표·설정 (아직 없는 화면은 '준비 중'으로) - 이번 주 목표를 넘기면 축하 한마디
운동 기록과 목표·설정 화면을 더했어요. 걷기 → 30분 → 기록하기 하면 위쪽 막대가 '이번 주 30분 / 150분 · 20%'로 바뀌어요.
  • 수영 35분 넣기 (30분 → + 한 번) → 막대가 늘어나는지
  • 목표를 100분으로 바꾸면 % 가 달라지는지

가족과 함께 쓸 저장소 — 내 구글 시트

15분

지금까지 기록은 내 브라우저 안에만 있습니다. 가족 휴대폰과 나누려면 인터넷 저장소가 필요합니다. 늘 쓰던 구글 시트를 저장소로 씁니다. 가족이 기록하면 시트에 한 줄씩 쌓이는 게 눈으로 보여요.

① 시트 만들기sheets.new (새 구글 시트) → 제목 예) 우리 운동일기 저장소
② 코드 넣기메뉴 확장 프로그램 → Apps Script → 안에 있는 글을 모두 지우고 아래 코드 상자를 복사 → 붙여 넣기 → 💾 저장
③ 배포오른쪽 위 배포 → 새 배포 → 톱니(유형 선택) → 웹 앱 → 실행: 나 · 액세스 권한: 모든 사용자 → 배포
④ 권한 승인액세스 승인 → 내 구글 계정 선택 → 아래 '경고 화면' 대로 → 허용
⑤ 주소 복사웹 앱 URL(https://script.google.com/macros/s/……/exec) 복사 → 메모장에 붙여 두기. 6번에서 씁니다
② 시트 코드 — 통째로 복사해 붙여 넣기
/* 우리 운동일기 — 구글 시트 저장소 (Apps Script) 1) 구글 시트에서 확장 프로그램 → Apps Script → 이 코드를 통째로 붙여 넣고 저장 2) 배포 → 새 배포 → 유형: 웹 앱 → 실행: 나 / 액세스 권한: 모든 사용자 → 배포 → 권한 승인 3) 나온 웹 앱 주소(…/exec)를 운동일기 index.html 의 SHEET_URL 에 넣기 시트 4장(모임·사람·기록·박수)은 처음 쓸 때 저절로 생깁니다. */ var SHEETS = { 모임: ['모임코드', '일기장이름'], 사람: ['모임코드', '사람ID', '이름', '주간목표(분)', '다짐', '시작'], 기록: ['모임코드', '사람ID', '이름', '날짜', '식사', '운동', '메모', '데이터', '고친 시각'], 박수: ['모임코드', '받는ID', '날짜', '보낸ID', '시각'] }; var KEYS = { 모임: [0], 사람: [0, 1], 기록: [0, 1, 3], 박수: [0, 1, 2, 3] }; // 같은 줄인지 알아보는 칸 // 가족 기록 모두 읽기 — 주소?code=모임코드 function doGet(e) { var code = clean_(e.parameter.code); if (code.length < 6) return out_({ error: 'code' }); var g = { title: '', members: {}, days: {}, claps: {} }; rows_('모임').forEach(function (r) { if (txt_(r[0]) === code) g.title = r[1]; }); rows_('사람').forEach(function (r) { if (txt_(r[0]) === code) g.members[txt_(r[1])] = { name: r[2], goalMin: Number(r[3]) || 150, pledge: r[4], joined: Number(r[5]) || 0 }; }); rows_('기록').forEach(function (r) { if (txt_(r[0]) !== code) return; var id = txt_(r[1]); (g.days[id] = g.days[id] || {})[txt_(r[3])] = JSON.parse(r[7] || '{}'); }); rows_('박수').forEach(function (r) { if (txt_(r[0]) !== code) return; var to = g.claps[txt_(r[1])] = g.claps[txt_(r[1])] || {}, d = txt_(r[2]); (to[d] = to[d] || {})[txt_(r[3])] = Number(r[4]); }); return out_(g); } // 기록 하나 쓰기·고치기·지우기 — {code, path, val} function doPost(e) { var b = JSON.parse(e.postData.contents), code = clean_(b.code), p = String(b.path || '').split('/'), v = b.val; if (code.length < 6) return out_({ error: 'code' }); var lock = LockService.getScriptLock(); lock.waitLock(10000); try { if (p[0] === 'title') put_('모임', [code], v == null ? null : [t_(code), v]); else if (p[0] === 'members') put_('사람', [code, p[1]], v == null ? null : [t_(code), t_(p[1]), v.name, v.goalMin, v.pledge || '', v.joined || '']); else if (p[0] === 'days') put_('기록', [code, p[1], p[2]], v == null ? null : [t_(code), t_(p[1]), name_(code, p[1]), t_(p[2]), meals_(v), ex_(v), v.memo || '', JSON.stringify(v), new Date()]); else if (p[0] === 'claps') put_('박수', [code, p[1], p[2], p[3]], v == null ? null : [t_(code), t_(p[1]), t_(p[2]), t_(p[3]), v]); } finally { lock.releaseLock(); } return out_({ ok: true }); } /* ---------- 도구 ---------- */ function sheet_(name) { var ss = SpreadsheetApp.getActive(), sh = ss.getSheetByName(name); if (!sh) { sh = ss.insertSheet(name); sh.appendRow(SHEETS[name]); sh.setFrozenRows(1); } return sh; } function rows_(name) { var v = sheet_(name).getDataRange().getValues(); v.shift(); return v; } function put_(name, key, row) { // 있으면 고치고, 없으면 새 줄, row가 null이면 지우기 var sh = sheet_(name), v = sh.getDataRange().getValues(); for (var i = 1; i < v.length; i++) { var same = KEYS[name].every(function (c, j) { return txt_(v[i][c]) === String(key[j]); }); if (!same) continue; if (row) sh.getRange(i + 1, 1, 1, row.length).setValues([row]); else sh.deleteRow(i + 1); return; } if (row) sh.appendRow(row); } function name_(code, id) { var n = ''; rows_('사람').forEach(function (r) { if (txt_(r[0]) === code && txt_(r[1]) === id) n = r[2]; }); return n; } function meals_(v) { return (v.meals || []).filter(Boolean).map(function (m) { return m.slot + ' ' + m.menu; }).join(', '); } function ex_(v) { return (v.ex || []).filter(Boolean).map(function (x) { return x.type + ' ' + x.min + '분'; }).join(', '); } function t_(s) { return "'" + s; } // 날짜·코드가 숫자로 바뀌지 않게 글자로 저장 function txt_(c) { return c instanceof Date ? Utilities.formatDate(c, Session.getScriptTimeZone(), 'yyyy-MM-dd') : String(c); } function clean_(s) { return String(s || '').toUpperCase().replace(/[^A-Z0-9-]/g, ''); } function out_(o) { return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }

코드는 클로드가 만든 것입니다. 파일로 받으려면 sheet-code.gs 내려받기. 시트 4장(모임 · 사람 · 기록 · 박수)은 처음 기록할 때 저절로 생깁니다.

⚠ 이 경고 화면이 나와도 괜찮아요 — 내가 방금 만든 코드라서 구글이 아직 확인하지 않았다는 뜻입니다.
"Google에서 확인하지 않은 앱" → 왼쪽 아래 고급 → (안전하지 않음)으로 이동 → 허용

⚠ 코드를 고친 뒤에는 배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포. "새 배포"를 또 누르면 주소가 바뀝니다.

누르는 즉시 보이는 더 빠른 방법(Firebase)도 있습니다. 앱은 주소 칸(DB_URL)만 바꾸면 그대로 쓸 수 있어요 — 수업 뒤 도전 과제.

모임 연결 — 가족 기록이 함께 보이게

핵심15분

엄마가 휴대폰에서 "걷기 40분"을 누르면, 20초 안에 내 화면에 "엄마님이 방금 걷기 40분을 기록했어요"가 뜹니다. 새로고침도, 다시 보내기도 필요 없습니다.

모임 만들기처음 시작할 때 새 모임 만들기 → 모임 코드(예: FIT-7K3Q)가 생김
초대하기함께 → 초대하기 → 주소 뒤에 ?g=모임코드가 붙은 링크를 카톡으로
들어오기가족이 링크 열기 → 이름만 적고 시작 → 같은 모임
휴대폰을 바꿔도같은 모임에 같은 이름으로 들어가면 "이어 쓸까요?" → 내 기록 그대로
프롬프트 6 — 모임 연결 (주소 칸만 내 것으로)
운동일기를 가족과 함께 쓰게 해줘. 회원가입 없이 '모임 코드'로 묶어. - 저장소: 내 구글 시트 웹 앱. 주소는 [5번에서 복사한 https://script.google.com/macros/s/……/exec]. 코드 맨 위에 SHEET_URL 한 줄로 둬 - 시트 코드 규칙(5번 코드): 읽기는 주소?code=모임코드 → 모임 전체(title·members·days·claps) 쓰기는 POST로 {code, path, val}. path는 members/내id, days/내id/날짜, claps/받는id/날짜/보낸id, title. 지우기는 val을 null로 POST는 헤더 없이 글자(JSON 문자열)로 보내 (그래야 막히지 않아) - 20초마다 새 기록을 가져오고, 앱을 다시 열었을 때도 바로 가져와 - 처음 화면에 [새 모임 만들기 / 초대받은 모임] 고르기. 새 모임이면 'FIT-' + 4글자 코드를 만들어 줘 - 주소에 ?g=코드 가 있으면 그 모임으로 들어오게. 이미 같은 이름이 있으면 '이 기기에서 이어 쓸까요?' 물어봐 - [함께] 화면: 모임 코드와 [초대하기](휴대폰은 공유창, 컴퓨터는 복사), 오늘의 소식(누가 무엇을 몇 분 전에 기록했는지), 가족별 이번 주 운동·연속 기록일·다짐·오늘 기록 - 가족 카드에 👏 박수 단추. 받은 박수는 내 기록 화면에 '엄마님이 박수를 보냈어요'로 - 다른 사람이 새로 기록하면 화면 아래에 '엄마님이 방금 걷기 40분을 기록했어요' 알림 - 인터넷이 끊겨도 내 기록은 먼저 저장해 두고, 다시 연결되면 올려 - 맨 위에 '구글 시트와 연결됨' 초록 점 - 받은 이름·메뉴·메모는 HTML로 해석되지 않게 안전하게 처리해
실시간 모임을 붙였어요. 모임 코드: FIT-7K3Q 함께 → 초대하기 → 카톡으로 링크 보내기 엄마가 링크를 열고 '엄마'로 시작하면 내 화면 '오늘의 소식'에 바로 나타나요. 엄마가 걷기 40분을 기록하면 → 20초 안에 "엄마님이 방금 걷기 40분을 기록했어요"
  • 짝과 짝지어 한 사람이 새 모임 만들기, 다른 사람은 모임 코드로 초대받은 모임
  • 짝이 운동을 기록하면 20초 안에 내 화면에 알림이 뜨는지 · 👏 박수를 주고받기
  • 내 구글 시트의 기록 시트에 '지애 · 점심 학교 급식 · 걷기 30분' 같은 줄이 생기는지

⚠ 내 컴퓨터에서 더블클릭해 연 파일로도 모임은 됩니다. 하지만 가족 휴대폰에서 쓰려면 9번에서 깃허브에 올린 주소로 초대하세요.

움직이는 대시보드

핵심15분

숫자가 올라가고, 막대가 자라고, 선이 그려지는 대시보드. 가족이 기록하면 저절로 바뀌어 긴장감이 생깁니다.

프롬프트 7 — 대시보드
대시보드 화면을 만들어줘. 우리 모임 전체를 비교하고, 움직임이 있게. - 기간 고르기: 이번 주 · 2주 · 30일 · 전체 (전체는 한 주씩 묶어서) - 요약 숫자 3개: 모임 전체 운동(분) · 오늘 기록한 사람(3/4) · 최장 연속 기록. 숫자는 0에서 올라가며 나타나게 - 주간 목표 레이스: 이번 주 달성률 순서대로 가로 막대, 각자 목표선은 점선, 막대가 차오르게 - 날짜별 운동 시간: 사람마다 색이 다른 묶음 막대. 이름을 눌러 켜고 끄기, 막대를 누르면 '엄마 · 10/27(화) · 45분' 표시. 막대가 아래에서 자라나게 - 쌓인 운동 시간: 사람별 누적 꺾은선, 선이 그려지는 효과, 끝에 이름과 숫자 (서로 겹치지 않게) - 어떤 운동을 했나: 운동 종류별 가로 막대 (사람 색으로 나눠서) - 식사 기록: 최근 14일, 사람마다 한 줄, 많이 적은 날일수록 진하게 - 가족이 새로 기록해 화면이 바뀔 때는 처음부터 다시 움직이지 말고, 이전 값에서 새 값으로 부드럽게 - 그래프는 외부 라이브러리 없이 SVG로, 사람 색은 모든 그래프에서 같게, 휴대폰 폭에서 잘리지 않게
대시보드를 만들었어요. 요약: 모임 전체 5,490분 · 오늘 3/4명 기록 · 최장 연속 47일(엄마) 주간 레이스: 1 지애 87% · 2 엄마 60% · 3 아빠 60% · 4 민지 20% 막대를 누르면 → "엄마 · 10/26(월) · 60분 등산"
  • 막대 하나 눌러 보기 · 이름 단추로 한 사람 껐다 켜기 · 전체로 바꿔 보기
  • 짝이 운동을 하나 더 넣으면 20초 안에 내 대시보드의 레이스 막대가 그 자리에서 늘어나는지
