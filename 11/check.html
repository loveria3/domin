수업 전 실제로 해 볼 것 점검표

교안에 적은 메뉴 이름·동작은 2026-10-10 공식 도움말 기준입니다. 앱 버전에 따라 다를 수 있어 수업 전 실제 앱에서 확인합니다. 체크 표시는 이 브라우저에만 저장됩니다.

공통 · 1차시 전

  • 강의장 와이파이에서 데스크톱 설치 파일 받기 속도 (느리면 USB 준비)
  • Firebase 규칙이 live/nov-1 ~ nov-4, nov-skills 경로 쓰기를 허용하는지 — 1.html?t=비밀번호로 강사 모드 켜고 다른 기기에서 '지금 여기' 따라오는지
  • 11월 패들렛 주소 확정 후 index·1~4차시의 공유 안내에 실제 링크 연결 (현재는 잘못된 링크 대신 안내문 표시)
  • 사전 안내 문자에 ready.html 주소 넣어 발송 (수업 3일 전)
  • Pro 계정·통합 화면 여부·폴더 연결·준비확인.txt 실제 저장 — 1차시 2번 '화면 지도'와 맞는지
  • 실습 서류의 스캔 PDF·사진(JPG) 글자를 코워크가 읽는지
  • 설정 → 사용량 화면 이름
  • 여행 사진 21장: 독사진 5 · 단체 9 · 풍경 5 · 음식 0 · 흐림 2(_19 · _20)를 맞게 고르는지, _06(지나가는 사람)·꽃(_11 · _12)을 헷갈리지 않는지, 선명도 숫자 계산(코드 실행)이 되는지
  • 사진 21장을 한 번에 볼 때 사용량이 얼마나 드는지 — 많으면 "10장씩 나눠서 봐줘"로 안내
  • 원본 백업 제외·확장자 유지·중복 집계 제외 확인, 서류 2건 원본 대조
  • 매 차시 필수 활동·휴식·개별 점검 합계 120분, 참고·도전은 선택으로 운영

2차시 전 — 커넥터 · 예약 · 스킬

  • 사용자 지정 → 커넥터 → ＋ → Google Calendar 연결 단계 수, 권한 화면 캡처
  • 남은 수업 2번(11/21·11/28) 등록 → 휴대폰 캘린더에 보이는지
  • 예약 작업: 사이드바 메뉴 이름, "지금 한 번 실행"이 되는지, 앱이 꺼져 있을 때 어떻게 되는지
  • 스킬 zip 8개 모두 업로드 → 시험 프롬프트로 스킬이 쓰이는지
  • 도민회사 주간보고: 매출 11,932,000원 · 달성률 99.4% · 전주 대비 +10.0% · 광고 클릭 2,340 / 전환 61 / 500,000원 · 리뷰 이벤트 [진행 중] · 개인 일정 제외 — 완성 예시(files/weekly-sample.docx)와 대조
  • 금요일 4시 예약 → 지금 실행으로 주간보고 폴더에 docx 저장되는지, 3주차 자료를 합친 뒤 다시 실행하면 11/20 보고서가 11/13 보고서를 '지난주'로 대조하는지
  • 수정본을 새 이름으로 업로드하고 원본을 끈 뒤 다른 입력에서도 규칙이 적용되는지
  • 프롬프트 생성기가 프롬프트 폴더에 TXT로 저장하는지
  • 기본 캘린더·2026년·Asia/Seoul·종료 시각·중복 방지 확인
  • 예약 결과 화면 확인·일시정지 시험. 주간보고 예약은 로컬 폴더를 읽으므로 데스크톱 앱이 켜져 있어야 함을 확인

3차시 전 — QR · 버셀 · 깃허브

  • 코워크가 QR 그림(png)을 직접 만드는지 — 안 되면 크롬 QR 대안으로 진행
  • 1번 프롬프트 0: 코워크가 원고.txt로 A4 두 장 pptx를 3~5분 안에 만드는지, 1장 오른쪽 아래에 이름이 QR 넣을 자리인 도형이 생기는지(4번이 이 도형을 찾음), 원고에 없는 내용을 넣지 않는지 — 안 되면 비상용 files/olle-practice.pptx로
  • 홍보물 꾸러미(files/olle-kit.zip → 올레홍보물.zip) 압축 풀면 홍보물 폴더에 원고.txt · 사진 폴더(7장) · 디자인지침.txt — 2번 프롬프트 1-2로 만든 페이지가 완성 예시(olle-sample)처럼 사진 머리 · 코스 썸네일 6(6은 1과 같은 사진) · 띠 사진 · 색 3가지 · 고정 바로가기로 나오는지, 올레안내/img에 사진 7장이 영문 이름으로 복사되는지
  • 4번 한 번 부탁으로 QR png 만들기 + 올레홍보물.pptx의 'QR 넣을 자리'에 넣기 + 홍보물_QR.pptx 저장까지 되는지 (PDF 변환은 도전 2)
  • 버셀: 폴더째 drop → Domains 주소 → 고친 폴더를 내 프로젝트 화면에 다시 끌어다 놓았을 때 같은 주소·같은 QR로 바뀐 내용이 보이는지 (폴더 재업로드는 꼭 미리 시험) · vercel-help.html#redeploy 그림(로그인·대시보드 카드는 그린 그림)이 실제 화면과 맞는지, 프로젝트 화면에 놓았을 때 Project Name 화면 없이 바로 새 배포가 되는지
  • github-help.html 그림 화면이 실제 GitHub 화면과 맞는지(메뉴 이름·위치). 깃허브 대안: 새 저장소 → 파일 업로드 → Settings → Pages(main/root) → 주소 확인 → Upload files로 갱신 시 같은 주소 반영(1~2분)
  • 각 수강생 계정의 남은 무료 사용량으로 실습 게시·갱신이 가능한지
  • 완성 예시 PDF의 QR은 loveria3.github.io/domin/11/olle-sample/를 가리킴 — olle-sample 폴더가 함께 올라가 있는지, 휴대폰으로 찍어 열리는지
  • 6번 웹교안: files/ai-compare.txt(2026-11-15 기준)의 요금·기능을 개강 전 공식 요금 페이지와 다시 대조 · 코워크가 index.html에 번호 단추 · 복사 단추 · 접히는 퀴즈를 두 번 부탁(① 번호·시간+번호 단추 ② 복사 상자+퀴즈)으로 붙이는지 · ai-class-sample.html과 비교
  • 7번 스킬: 코워크가 web-lesson.zip(안 폴더 이름 web-lesson, SKILL.md)을 AI교실 폴더에 만드는지 → 사용자 지정 → 스킬 → ＋ 업로드 → 새 대화에서 프롬프트 6으로 같은 모양의 교안이 나오는지 (12분 안에)
  • 8번 반응형: 프롬프트 7-1·7-2 뒤 올레안내·AI교실 두 페이지가 창을 넓히면 두 단, 좁히면 한 줄로 바뀌고 휴대폰 모양(글씨 크기·가로 스크롤 없음)이 그대로인지 — 완성 예시 olle-sample·ai-class-sample.html을 PC 창에서 같이 보여 주기
  • 강사 계정으로 HTML·QR 삽입 PPTX·PDF 완성본을 만들어 비상 자료로 보관. 예시 QR과 학습자 주소 구분
  • 원본에 없는 거리·코스·우천 운영을 추측하지 않는지 확인

4차시 전 — 보관함

  • 보관함 틀 + 프롬프트 TXT 18개로 채우기 → 검색·분류·복사 작동
  • 새 분류(예: 회사)가 있어도 단추가 생기는지
  • 갤럭시·아이폰 '홈 화면에 추가' 메뉴 이름
  • 휴대폰에서 복사하기 → 클로드 앱에 붙여 넣기 작동
  • 준비 조건 표시·원본 하위 폴더 제외·새 프롬프트 1개 추가·같은 주소 갱신 확인
  • 실제 Claude 실행·계정 인증·예약 실행은 교안 파일 점검과 별도로 강사가 시험

6차시 전 — AI교육 소식 검색함

  • 강사 계정으로 files/keyword-script.txt를 새 시트에 붙여 setup 실행 → 키워드·검색함 탭 생성, 실제 구글 뉴스 기사가 들어오는지 (가짜 환경 시험만 해 둠)
  • 웹 앱 배포(나 · 모든 사용자) → keyword-app.html에 주소 넣고 PIN·지금 검색·보관·버림·키워드 저장·예약 켜기 실제 작동
  • 예약 켜기 → 편집기 ⏰ 트리거에 dailySearch 1개, 다음 날 아침 새 줄 들어왔는지
  • AI교육 기본 키워드 5개로 잡음 비율 보기 → 빼는 말 기본값 조정 (교안 3번 예시와 맞추기)
  • '확인되지 않은 앱' 화면 실제 문구 캡처 → 이론 ② 6번 · 6차시 4번 ④ 표현 맞추기
  • 강사 공용 웹 앱 URL · PIN 준비 → 6차시 4번 🆘 자리표시 [강사 공용 웹 앱 URL] 채우기, 수업 뒤 배포 보관
  • 휴대폰 클로드 앱 + 구글 드라이브 커넥터로 시트 '보관' 줄 요약이 되는지 (안 되면 10번을 CSV 올리기로)
  • 버셀에 올린 주소에서 앱스크립트 호출이 되는지 (파일 더블클릭 때와 같은지)
