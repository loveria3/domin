강사용 · 자료실에 링크하지 않은 페이지

수업 전 실제로 해 볼 것 점검표

교안에 적은 메뉴 이름·동작은 2026-10-10 공식 도움말 기준입니다. 앱 버전에 따라 다를 수 있어 수업 전 실제 앱에서 확인합니다. 체크 표시는 이 브라우저에만 저장됩니다.

1

공통 · 1차시 전

  • 강의장 와이파이에서 데스크톱 설치 파일 받기 속도 (느리면 USB 준비)
  • Firebase 규칙이 live/nov-1 ~ nov-4, nov-skills 경로 쓰기를 허용하는지 — 1.html?t=비밀번호로 강사 모드 켜고 다른 기기에서 '지금 여기' 따라오는지
  • 11월 패들렛 주소 확정 후 index·1~4차시의 공유 안내에 실제 링크 연결 (현재는 잘못된 링크 대신 안내문 표시)
  • 사전 안내 문자에 ready.html 주소 넣어 발송 (수업 3일 전)
  • Pro 계정·통합 화면 여부·폴더 연결·준비확인.txt 실제 저장 — 1차시 2번 '화면 지도'와 맞는지
  • 실습 서류의 스캔 PDF·사진(JPG) 글자를 코워크가 읽는지
  • 설정 → 사용량 화면 이름
  • 원본 백업 제외·확장자 유지·중복 집계 제외 확인, 서류 2건 원본 대조와 복구 실습 시험
  • 매 차시 필수 활동·휴식·개별 점검 합계 120분, 참고·도전은 선택으로 운영
2

2차시 전 — 커넥터 · 예약 · 스킬

  • 사용자 지정 → 커넥터 → ＋ → Google Calendar 연결 단계 수, 권한 화면 캡처
  • 공지 예시로 일정 3개 등록 → 휴대폰 캘린더에 보이는지
  • 예약 작업: 사이드바 메뉴 이름, "지금 한 번 실행"이 되는지, 앱이 꺼져 있을 때 어떻게 되는지
  • 스킬 zip 7개 모두 업로드 → 시험 프롬프트로 스킬이 쓰이는지
  • 수정본을 새 이름으로 업로드하고 원본을 끈 뒤 다른 입력에서도 규칙이 적용되는지
  • 프롬프트 생성기가 프롬프트 폴더에 TXT로 저장하는지
  • 수업연습 캘린더·2026년·Asia/Seoul·종료 시각·중복 방지 확인
  • 클라우드 예약 결과 화면 확인·일시정지 시험. 로컬 저장은 기본 실습에서 제외
3

3차시 전 — QR · 넷리파이

  • 코워크가 QR 그림(png)을 직접 만드는지 — 안 되면 크롬 QR 대안으로 진행
  • pptx의 'QR 넣을 자리'에 그림을 넣고 PDF로 변환하는지
  • 넷리파이 Deploys 탭의 끌어다 놓기 칸 문구, 다시 올린 뒤 같은 QR로 바뀐 내용이 보이는지
  • 각 수강생 계정의 남은 무료 사용량으로 실습 게시·갱신이 가능한지
  • 강사 계정으로 HTML·QR 삽입 PPTX·PDF 완성본을 만들어 비상 자료로 보관. 예시 QR과 학습자 주소 구분
  • 원본에 없는 거리·코스·우천 운영을 추측하지 않는지 확인
4

4차시 전 — 보관함

  • 보관함 틀 + 프롬프트 TXT 18개로 채우기 → 검색·분류·복사 작동
  • 새 분류(예: 회사)가 있어도 단추가 생기는지
  • 갤럭시·아이폰 '홈 화면에 추가' 메뉴 이름
  • 휴대폰에서 복사하기 → 클로드 앱에 붙여 넣기 작동
  • 준비 조건 표시·원본 하위 폴더 제외·새 프롬프트 1개 추가·같은 주소 갱신 확인
  • 실제 Claude 실행·계정 인증·예약 실행은 교안 파일 점검과 별도로 강사가 시험
5

화면 캡처 넣을 자리 (강사가 직접 찍기)

2차시 4번예약된 작업 목록
2차시 6번사용자 지정 → 스킬 → ＋ → 업로드 화면
