이미지 만들 때 힘이 되는 추천 스킬 10

포스터·카드뉴스·움직이는 그림·브랜드 색 맞추기까지. 많이 쓰이는 스킬 10가지를 쉬운 말로 골라 모았습니다.

클로드에게 "포스터 만들어줘" 했더니 매번 색도 글꼴도 제각각이었나요?

클로드는 사진을 찍듯 그리는 대신 코드로 그림을 그립니다(PNG·PDF·GIF·웹 화면). 스킬을 켜 두면 디자인 규칙을 먼저 읽고 그려서 결과가 훨씬 가지런해집니다.

먼저 알아 둘 것 — 스킬은 두 종류

3분
앱에서 바로 (①~⑧)Anthropic이 만든 공식 스킬. 사용자 지정 → Skills 목록에 있으면 켜기만 하면 되고, 없으면 깃허브에서 받아 zip으로 올립니다. 추가 비용 없음.
클로드 코드용 (⑨~⑩)다른 사람이 만든 공개 스킬. 개발자 도구(클로드 코드)에 설치하고, ⑨는 다른 회사 이미지 AI 열쇠(API 키)와 요금이 따로 듭니다. 수업 후 궁금한 분만.
🖼 진짜 사진 같은 그림(사람 얼굴, 풍경 사진)은 클로드 혼자 못 그립니다. 그런 그림은 ⑨처럼 이미지 AI와 이어 주는 스킬이 필요해요.

공식 스킬 켜는 법

5분
  1. 설정 → 기능 → 클라우드에서 코드 실행이 켜져 있는지 확인 (2차시 설정 단계)
  2. 왼쪽 사용자 지정 → Skills → Anthropic 스킬 목록에서 이름을 찾아 켜기
  3. 목록에 없으면: 카드의 살펴보기 → 깃허브 폴더를 클로드에게 보여 주고 이 스킬을 올릴 수 있게 zip으로 묶어줘 → ＋ → 스킬 업로드
  4. 부탁할 때 이름을 넣으면 확실해요 — canvas-design 스킬로
4

시험 프롬프트 — 하나씩 해 보기

10분
🖼 canvas-design · 포스터
canvas-design 스킬로 [11월 28일 토요일 10시, 제주도민대학 수료식] 포스터를 A4 세로 PNG로 만들어줘. 따뜻한 귤색 계열, 글자는 크게, 날짜·장소가 한눈에 보이게.
🎨 theme-factory · 색 통일
theme-factory 스킬에 있는 테마 10가지를 이름과 색 견본으로 먼저 보여줘. 내가 고르면 방금 만든 포스터에 그 테마를 입혀줘.
📑 pptx · 카드뉴스
pptx 스킬로 [겨울철 귤 보관법] 카드뉴스 5장을 정사각형 슬라이드로 만들어줘. 1장은 제목, 2~4장은 한 장에 한 가지 요령, 5장은 정리. 다 만들면 장마다 PNG 그림으로도 저장해줘.
🛠 skill-creator · 내 이미지 스킬
skill-creator 스킬로 「우리 가게 홍보물」 스킬을 만들어줘. 색은 [남색과 귤색], 글꼴은 굵고 둥근 느낌, 맨 아래에 가게 이름과 전화번호를 꼭 넣기. 완성되면 올릴 수 있는 zip으로 줘.

주의할 점

2분
  • 출처를 모르는 스킬은 올리지 않기 — 공식(①~⑧) 먼저, 공개 스킬은 SKILL.md를 읽어 보고
  • 남의 사진·로고·캐릭터를 흉내 내 달라고 하지 않기 — 저작권 문제
  • 스킬을 한꺼번에 많이 켜면 규칙이 섞여요 — 필요한 것만 켜고 다 쓰면 끄기
  • ⑨처럼 API 키가 필요한 스킬은 요금이 나갈 수 있으니 한도 먼저 확인
