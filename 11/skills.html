회사에서 많이 쓰는 스킬 · 커넥터 안내서

내려받아 저장하는 추천 스킬 7개와, 회사에서 자주 연결하는 커넥터(MCP)를 한 장에 모았습니다.

같은 회의록을 사람마다 다르게 쓰고, 같은 자료를 매번 메일·드라이브에서 찾아 옮기고 있다면?

스킬은 "어떻게 일할지"를, 커넥터는 "어디에 닿을지"를 클로드에게 알려 줍니다. 둘을 함께 쓰면 한마디 부탁이 회사 양식 그대로의 결과물이 됩니다.

스킬 저장하는 법 · 안 될 때

  1. 카드의 내려받기 → zip 그대로 둡니다 (압축 풀지 않기)
  2. 클로드 왼쪽 사용자 지정(Customize) → 스킬(Skills)
  3. ＋ → 스킬 만들기 → 스킬 업로드 → zip 선택
  4. 목록에 생긴 스킬이 켜짐인지 확인 → 시험 프롬프트로 확인
스킬 메뉴가 없어요설정 → 기능 → 코드 실행 및 파일 생성을 먼저 켜세요
올리기가 실패해요zip을 풀었다가 다시 묶었나요? 강사 파일을 그대로 다시 받아 올려 보세요
스킬을 안 써요부탁에 스킬 이름을 넣어 주세요 — "회의록 정리 스킬로 해줘"
내 식으로 바꾸고 싶어요"meeting-minutes 스킬에 '참석자 서명란'을 추가해서 zip으로 다시 만들어줘" → 새 zip을 올리기

스킬 안에는 무엇이 들었나 궁금한 분만

zip을 열어 보면 SKILL.md 파일 하나가 있습니다. 맨 위에 이름과 언제 쓰는지(설명), 아래에 순서 · 양식 · 지킬 것이 우리말로 적혀 있어요. 클로드는 평소엔 이름과 설명만 보고 있다가, 관련 부탁이 오면 그때 본문을 꺼내 읽습니다. 그래서 스킬을 여러 개 저장해도 느려지지 않습니다.

회사에서 많이 쓰는 커넥터 (MCP)

업무 활용

사용자 지정 → 커넥터 → ＋ 에서 골라 내 계정으로 로그인하면 연결됩니다. 전체 목록은 claude.ai/connectors.

분야커넥터이런 부탁을 해요
일정Google Calendar · Outlook 일정"다음 주 비어 있는 오후 시간 찾아서 회의 잡아줘" · "회의 전 준비할 것 정리"
메일Gmail · Outlook (Microsoft 365)"답장 안 한 메일 중 급한 것 5개" · "이 메일에 회신 초안 써서 임시 저장"
파일Google Drive · OneDrive · SharePoint"작년 사업계획서 찾아서 올해 초안과 다른 점 표로"
메신저Slack · Microsoft Teams"이번 주 팀 채널에서 결정된 것만 요약" · "공지 초안 써줘"
문서 · 위키Notion · Confluence"회의록을 노션 '회의' 페이지에 올려줘" · "업무 매뉴얼에서 휴가 규정 찾아줘"
업무 관리Asana · Jira · Linear · Monday"회의록의 할 일을 담당자별 업무 카드로 만들어줘"
디자인Canva · Figma"이 행사 안내문으로 캔바 포스터 초안 만들어줘"
영업 · 고객HubSpot · Salesforce"이번 달 연락 안 한 고객 목록과 안부 메일 초안"
요금제별 차이 — Pro·Max는 내가 직접 연결합니다. Team·Enterprise(회사 계정)는 관리자가 먼저 허용한 커넥터만 보이고, 각자 자기 계정으로 로그인합니다. 목록에 없으면 회사 IT 담당자에게 문의하세요.

커넥터 이름과 제공 여부는 바뀔 수 있습니다. 실제 목록은 클로드의 커넥터 화면에서 확인하세요.

더 찾아보기 — 공식 예제 스킬

심화

Anthropic이 공개한 예제 스킬 모음 github.com/anthropics/skills 에도 회사에서 쓸 만한 것이 있습니다 (영어).

internal-comms사내 공지, 현황 보고, 뉴스레터 같은 사내 소통 글
doc-coauthoring긴 문서를 같이 쓰고 다듬는 순서

GitHub에서 받으려면 폴더를 zip으로 묶어야 해서 조금 번거롭습니다. 클로드에게 "이 스킬을 업로드용 zip으로 만들어줘"라고 부탁하면 편합니다. 영어 스킬도 한국어로 부탁하면 한국어로 답합니다.

회사에서 쓸 때 보안 수칙

꼭
  • 회사 규정 먼저 — 고객 정보·인사 자료·기밀을 외부 AI에 올려도 되는지 확인
