공통

  • 패들렛 주소 확정 → 1~4.html의 PADLET-ADDRESS 자리 4곳 바꾸기 (1차시 2곳, 2·3·4차시 각 1곳)
  • Firebase 규칙이 live/doson-1 ~ doson-4 경로 쓰기를 허용하는지 — 1.html?t=비밀번호로 강사 모드 켜고 다른 기기에서 '지금 여기' 따라오는지
  • 마음에도순 와이파이·빔프로젝터·멀티탭 (노트북 10대)
  • 무료 계정 하루 사용량 — 한 차시 안에서 몇 번까지 부탁할 수 있는지 감 잡기

차시별

  • 1차시 — 김장 안내문·약 봉투 사진(img/)의 글자를 정확히 읽는지 · 웹 검색 켜는 위치 · 출처 링크가 붙는지
  • 2차시 — 무료 시험 계정에 Publish(로그인 없이 열리는 링크)가 있는지, 새 Share 화면만 있는지 (Share 링크는 받는 사람도 클로드 계정 필요)
  • 2차시 — PlayMCP '카카오톡 나에게 보내기' 도구함 → 사용자 정의 커넥터 추가 → 나와의 채팅 전송 (무료 계정 1개 제한)
  • 3차시 — GitHub zip을 클로드로 hwpx.zip(폴더 이름 hwpx)으로 다시 묶어 업로드되는지 — 폴더 이름이 스킬 이름과 달라 그대로는 실패할 수 있음. 라이선스 표시가 없는 저장소라 강사가 묶은 zip을 배포하지 않고 각자 묶게 함. 무료 계정에서 .hwpx가 실제로 만들어지고 한글에서 열리는지 (안 되면 docx 대안)
  • 3차시 — Gmail 커넥터 연결 위치와 권한 화면, 최근 7일 요약이 되는지
  • 4차시 — "스킬 만들어줘"로 zip(.skill)이 나오는지, 업로드 후 새 대화에서 "공지 써줘"에 스킬이 쓰이는지 · 예비용 skills/moim-notice.zip
  • 4차시 — 「내앱」 폴더째 vercel.com/drop → 폰에서 index·장부·발표자료 열림 → 내 프로젝트 화면에 다시 끌어다 놓아 같은 주소 갱신
