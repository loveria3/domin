웹 발표자료 만들기

오늘의 핵심25분

파란 글씨 네 군데만 고쳐서 보내세요. 나머지 조건은 그대로 두세요 — 그래야 4차시에 인터넷에 올리기 쉽습니다.

프롬프트 3 — 웹 발표자료 (통째로 복사)
너는 발표자료를 잘 만드는 디자이너야. [우리 마을 도순동 자랑] 발표자료를 웹페이지로 만들어줘. 듣는 사람은 [명절에 모인 가족과 손주들] 이야. [내용] - 모두 8장. 1장은 표지, 8장은 마무리 인사 - 꼭 넣을 내용: [도순 녹차밭, 귤밭과 돌담, 마을 김장 잔치, 내가 좋아하는 산책길] - 한 장에 글은 세 줄 이내, 큰 글씨로 [모양] - 한 화면에 한 장씩 보이고, 화면 양쪽에 큰 화살표 단추로 넘기게 해줘 - 키보드 왼쪽·오른쪽 방향키로도 넘어가게 - 오른쪽 아래에 '3 / 8' 처럼 쪽 번호 - 분위기는 [밝고 따뜻하게, 귤색과 초록색] - 폰에서 열어도 잘 보이게 [꼭 지킬 것] - html 파일 하나로 만들어줘 - 인터넷에서 따로 불러오는 것 없이 만들어줘
  • 오른쪽에 표지가 떴는지
  • 화살표 단추를 눌러 8장까지 넘어가는지
  • 내가 부탁한 내용이 다 들어갔는지

⚠ 클로드는 날짜·장소·숫자를 그럴듯하게 지어낼 수 있습니다. 내가 알려 주지 않은 숫자는 꼭 확인하세요.

원하는 곳만 고치기

15분

다시 만들어 달라고 하지 않습니다. 고칠 곳만 말합니다. 아래에서 필요한 것만 골라 쓰세요.

고치기 ① 글씨
모든 장의 글씨를 지금보다 한 단계 크게 해줘. 나머지는 그대로 둬.
고치기 ② 색
색만 [바다 느낌의 파란색] 계열로 바꿔줘. 내용은 그대로 둬.
고치기 ③ 한 장 더
[5장] 뒤에 [마을 어르신이 들려준 옛이야기] 장을 하나 더 넣어줘. 쪽 번호도 맞춰줘.
고치기 ④ 한 장만 바꾸기
[3장] 의 내용을 [귤 맛있게 고르는 법 세 가지] 로 바꿔줘. 다른 장은 건드리지 마.
고치기 ⑤ 재미 한 스푼
장이 넘어갈 때 부드럽게 넘어가는 효과를 넣고, 표지에 어울리는 이모지를 크게 하나 넣어줘.
🔑 주문 공식 — "[어디]를 [어떻게] 바꿔줘. 나머지는 그대로 둬."

링크 만들기 · 파일로 받아 두기

10분

완성한 발표자료를 두 가지 방법으로 챙깁니다. 오늘은 링크로 보내고, 파일은 4차시에 내 주소로 올릴 때 씁니다.

① 공유 링크 — 바로 보내기

  1. 아티팩트 오른쪽 위 공개(Publish) 단추 → 공개 → 링크 복사 → 메모장에 붙여 두기
  2. 크롬 시크릿 창(Ctrl + Shift + N)에 붙여넣어 로그인 없이도 열리는지 확인
시크릿 창에서 열려요성공! 가족 누구나 바로 엽니다 → 7번에서 카톡으로 보내요
'공유(Share)'만 보여요
/ 로그인하라고 나와요		화면 종류에 따라 받는 사람도 클로드 계정이 있어야 열리는 링크입니다. 오늘은 그 링크로 연습하고, 가족에게 보낼 진짜 주소는 4차시에 버셀로 만듭니다.

⚠ 공개한 링크는 주소를 아는 누구나 볼 수 있습니다. 전화번호·집 주소 같은 개인정보는 빼고 공개하세요. 다시 비공개로 바꿀 수도 있습니다.

② 파일로 받아 두기 — 4차시에 씁니다

  1. 아티팩트 오른쪽 위 다운로드(↓) 단추 → 파일 받기
  2. 다운로드 폴더에서 받은 파일을 더블클릭 → 크롬에서 열리면 성공
  3. 파일 이름을 slides.html 로 바꿔 문서 폴더에 두기

다운로드가 안 되면 → 위의 예시 파일 내려받기로 받아 두세요. "html이 안 보여요" → 확장자가 숨겨진 것입니다. slides 까지만 바꾸면 됩니다.

카카오톡 커넥터 연결하기

오늘의 핵심15분

커넥터는 클로드에게 다른 서비스로 들어가는 출입증을 주는 것입니다. 오늘은 클로드가 내 카톡 '나와의 채팅'에 글을 보낼 수 있게 출입증을 줍니다.

① 카카오 도구함 만들기 (처음 한 번만)

PlayMCP크롬 검색창에 PlayMCP 검색 → 카카오가 만든 사이트 들어가기 → 카카오 로그인
담기도구 목록에서 '카카오톡 나에게 보내기' 찾기 → 도구함에 담기
주소 복사내 도구함 → 도구함 주소(URL) 복사

② 클로드에 연결하기

커넥터클로드 왼쪽 아래 내 이름 → 설정 → 커넥터 → 사용자 정의 커넥터 추가
붙여넣기이름은 카카오톡, 주소 칸에 복사한 도구함 주소 붙여넣기 → 추가
허용연결을 누르면 카카오 로그인 창 → 허용
연결 확인 프롬프트
카카오톡 나와의 채팅방에 "클로드 연결 성공! 🎉" 이라고 보내줘.
  • 클로드가 보내도 되는지 물어보면 내용을 읽고 허용
  • 휴대폰 카카오톡 → 나와의 채팅에 글이 왔는지 확인

⚠ 무료 계정은 이런 사용자 정의 커넥터를 하나만 붙일 수 있습니다. 카카오톡 하나만 연결해 두세요.

연결이 안 되면 그냥 넘어갑니다 — 7번에서 클로드가 써 준 글을 복사해서 카톡에 붙여넣어도 결과는 같습니다. 안 되는 부분은 개별 점검 시간에 함께 봅니다.

프롬프트 4 — 내 발표자료 초대장 보내기
내 발표자료 링크는 [5번에서 복사한 링크] 야. 이 발표자료를 소개하는 짧은 초대 글을 3줄로 써서 카카오톡 나와의 채팅방에 보내줘. 마지막 줄에 링크를 꼭 넣어줘. 보내기 전에 글을 먼저 보여줘.
  1. 폰 카카오톡 → 나와의 채팅에서 확인 → 링크 눌러 열어 보기
  2. 마음에 들면 전달 눌러 가족·모임 단톡방으로
  3. 패들렛에 "2차시 — [내 이름]" + 링크 올리고, 다른 분 링크도 눌러 구경하기 👀
