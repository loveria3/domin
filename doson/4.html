나만의 스킬 만들기 — 대화로

오늘의 핵심22분

3차시에는 남이 만든 스킬(한글)을 올렸습니다. 오늘은 클로드와 대화하며 내 스킬을 직접 만듭니다.

프롬프트 1 — 스킬 만들기 (통째로 복사)
나만의 스킬을 만들고 싶어. 업로드할 수 있는 스킬 zip 파일로 만들어줘. - 스킬 이름: [moim-notice] (영어 소문자와 - 만) - 하는 일: [우리 동창회 단톡방 공지 쓰기] - 이럴 때 꺼내 써: ["공지 써줘", "단톡방 안내", "모임 알림"] 이라고 할 때 - 꼭 지킬 것: [날짜(요일)·장소·회비를 맨 위 세 줄에] [이모지는 그 세 줄에만, 전체 10줄 이내] [모르는 건 지어내지 말고 ○○로 비우기] [끝인사는 '늘 고맙습니다. 총무 ○○○ 드림'] 업로드 규칙도 지켜줘: zip 안의 폴더 이름은 스킬 이름과 똑같이, 설명(description)은 150자 이내. 만들기 전에 궁금한 게 있으면 두세 개만 물어봐.
  1. 클로드의 질문에 답하기 → zip 파일(또는 .skill 파일)이 생기면 내려받기
  2. 왼쪽 사용자 지정(Customize) → 스킬 → ＋ → 스킬 만들기 → 스킬 업로드 → 방금 받은 파일 (3차시와 같은 방법)
  3. 목록에 내 스킬이 켜짐인지 확인
스킬 파일을 만들었어요 → moim-notice.zip 안에 든 것: SKILL.md (이름 · 언제 쓰는지 · 순서 · 결과 모양 · 지킬 것) 설정 → 기능 → 스킬에서 업로드하면 바로 쓸 수 있어요.

답 화면에 '스킬로 저장' 같은 단추가 보이면 그걸 눌러도 됩니다. 파일이 안 만들어지면 위의 예시 스킬(모임 공지) ↓을 받아 올리고 다음 단계로 가세요. 스킬은 3차시처럼 코드 실행 및 파일 생성이 켜져 있어야 만들어집니다.

새 zip을 올리기 전에 목록에서 예전 스킬을 끄거나 지우고 올리세요. 같은 이름이 두 개면 헷갈립니다.

생활 앱 만들기 — 경조사비 장부

오늘의 핵심28분

"그 집 아들 결혼식 때… 내가 얼마 했더라?" 오늘은 이 고민을 끝내는 나만의 앱을 만듭니다. 코딩은 한 줄도 안 합니다 — 말로 부탁만 합니다.

  1. 새 대화를 열지 마세요. 앱은 대화창 하나로 끝까지 갑니다.
  2. 안 될 때 "다시 만들어줘" 금지 → "○○ 부분만 고쳐줘"
  3. 단계가 끝날 때마다 아티팩트 오른쪽 위 다운로드 — 되돌아갈 자리입니다.

⚠ 수업 중에는 가상 이름 · 가상 금액으로만 연습합니다. 진짜 지인 이름은 집에서 넣으세요.

프롬프트 3 — 1단계: 적고 · 찾고 · 목록 보기
경조사비 장부 웹앱을 아티팩트로 만들어줘. 제목은 [강지애]의 경조사비 장부 라고 해줘. [적는 칸] 이름 / 관계(가족·친척·친구·직장·이웃·기타 중 고르기) / 행사(결혼·장례·돌잔치·칠순팔순·개업·기타 중 고르기) / 날짜 / 금액(원) / 주고받음(냈음·받았음 중 고르기) [적기] 적기 단추를 누르면 아래 목록에 쌓이게, 최근 날짜가 맨 위. 금액은 50,000원 처럼 쉼표. 냈음은 파란 글씨, 받았음은 초록 글씨. 줄마다 지우기 단추, 지우기 전에 한 번 묻기. [찾기] 목록 위에 찾기 칸. 이름 한 글자만 쳐도 걸러지고, 찾은 사람과 주고받은 합계(낸 돈·받은 돈)를 위에 크게. [연습용] '연습 기록 넣기' 단추를 누르면 제주 느낌의 가상 기록 10개가 들어가게. [저장] 적은 내용은 이 브라우저에 저장해서, 창을 닫았다 열어도 남아 있게. 미리보기에서 저장이 안 되면 오류 없이 넘어가게. [꼭 지킬 것] html 파일 하나로, 인터넷에서 따로 불러오는 것 없이. 글씨는 크게, 단추에는 무슨 일이 일어나는지 한글로.
  • 제목에 내 이름이 떴는지 — 내가 만든 앱입니다!
  • 연습 기록 넣기 → 성 한 글자로 찾기 → "낸 돈 ○원 · 받은 돈 ○원"이 나오는지
프롬프트 4 — 2단계: 합계 · 백업 · 큰 글씨
앞에서 만든 것은 그대로 두고 이것만 더해줘. - 연도를 고르면 그 해에 낸 돈·받은 돈 합계를 크게, 그 아래 행사별 합계 표. - '백업 받기' 단추: 장부 내용을 파일 하나로 내려받게(파일 이름에 오늘 날짜). '백업 불러오기' 단추: 그 파일을 고르면 다시 들어오게. 불러올 때 바꿀지 합칠지 물어봐줘. - 글씨와 단추를 더 크게, 폰에서 한 손으로 쓰기 좋게. 색은 [따뜻한 베이지 바탕에 진한 초록 단추].
  • 행사별 합계를 더하면 전체 합계와 같은지 — 손으로 한 번 검산
  • 아티팩트 다운로드 → 파일 이름을 jangbu.html 로 바꿔 문서 폴더에
⚠ 알아 둘 것장부 내용은 이 컴퓨터의 이 크롬에만 저장됩니다. 폰에서 열면 빈 장부입니다.
😊 좋은 점내 경조사 기록이 남의 서버에 올라가지 않습니다. 그래서 백업 파일로 옮깁니다.
안 될 때만 — 화면이 하얗게 나오면
화면이 하얗게 나와. 무슨 문제인지 찾아서 고쳐줘. 지금 있는 기능은 그대로 둬.

장부 말고 다른 앱이 좋다면

💊 약 먹기 체크표"아침·점심·저녁 약 먹었으면 누르는 큰 단추, 오늘 날짜, 일주일 기록 표"
💰 우리 모임 회비 장부"회원 이름별 이번 달 냈음/안 냄, 총 모인 돈, 안 낸 사람만 보기"
🍊 귤 주문 장부"주문자·수량·입금 여부·택배 보냄 체크, 오늘 보낼 것만 보기"

위 프롬프트 3의 [적는 칸]·[적기]만 바꾸면 됩니다. 다른 앱도 파일 이름은 영어로(예: yak.html) 저장하세요.
