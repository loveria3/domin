1차시 · 처음 한 번 · 모두 함께

기본 설정 맞추기

강사 화면을 보며 모두 똑같이 켜 둡니다. 4주 내내 같은 화면으로 따라오기 위해서예요.

1

코드 실행 켜기

내 이름(왼쪽 아래)→설정→기능

그림 예시
① 코드 실행 및 파일 생성한글·엑셀 파일, 스킬 만들기
② 아티팩트함께 켜짐 — 맨 아래 시험 부탁으로 확인

① 코드 실행 및 파일 생성만 켜면 됩니다. ② 아티팩트는 함께 켜지고, 맨 아래 시험 부탁으로 확인해요. 메뉴가 영어면 내 이름 → Language → 한국어 먼저.

2

웹 검색 켜기

입력창 왼쪽 아래 ＋→맨 아래 웹 검색→✓ 표시

오른쪽에 ✓가 보이면 켜진 것입니다. "웹에서 찾아서, 출처 붙여서"가 이것으로 됩니다.

3

허용 창이 뜨면

구글·카카오 로그인 후 권한 화면커넥터 연결할 때허용
클로드가 읽기 전에 확인메일 읽기 · 웹 검색허용
클로드가 보내기·지우기 전에 확인카톡 보내기 · 메일 보내기읽고 한 번 허용

⚠ '항상 허용'은 보내기·지우기에는 누르지 않기. 크롬의 마이크·다운로드 허용 창은 허용.

4

차시마다 하나씩 더

  • 1차시Gmail 연결 (시간 나면)
  • 2차시카카오톡 연결 — 카카오 계정 필요
  • 3차시한글 스킬 올리기
  • 4차시나만의 스킬 올리기

하는 방법은 그 시간 교안에 있습니다.
