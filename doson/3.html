스킬이 뭔가요? — 한글 스킬 설치하기

15분

스킬은 클로드에게 주는 업무 매뉴얼입니다. 클로드는 원래 한글(.hwpx) 파일 만드는 법을 잘 모릅니다. 그 방법을 적어 둔 한글 스킬을 넣어 주면 한글 파일로 바로 만들어 줍니다.

커넥터스킬
비유출입증 (2차시 카톡)업무 매뉴얼 (오늘 한글)
정하는 것어디에 닿나어떻게 일하나
모양목록에서 골라 로그인SKILL.md가 든 zip 파일

① 먼저 켜 둘 것

클로드 왼쪽 아래 내 이름 → 설정 → 기능(Capabilities) → 코드 실행 및 파일 생성 켜기

② 한글 스킬 내려받기

  1. 위의 한글(hwpx) 스킬 받으러 가기 → GitHub 페이지가 열려요
  2. 초록색 Code 단추 → 맨 아래 Download ZIP
  3. 다운로드 폴더에 hwpxskill-main.zip이 생기면 — 압축 풀지 않고 그대로 둡니다

③ 업로드용으로 다시 묶기 — 클로드에게 맡기기

스킬 zip은 안의 폴더 이름이 스킬 이름과 같아야 올라갑니다. GitHub에서 받은 파일은 폴더 이름이 hwpxskill-main이라 맞지 않아요. 이 정리를 클로드에게 시킵니다.

스킬 다시 묶기
첨부한 zip은 한글(hwpx) 스킬이야. 클로드 스킬 업로드용으로 다시 묶어줘. - SKILL.md 맨 위의 name 값과 똑같은 이름의 폴더 하나에 모든 파일을 넣어 - tests 폴더와 .gitignore는 빼고, 나머지 내용은 고치지 마 - 결과를 hwpx.zip 으로 내려받게 해줘

입력창 ＋로 hwpxskill-main.zip을 첨부하고 위 문장을 보내세요. 받은 hwpx.zip을 다음 단계에서 올립니다.

④ 클로드에 올리기

  1. 왼쪽 사용자 지정(Customize) → 스킬(Skills)
  2. ＋ → 스킬 만들기(Create skill) → 스킬 업로드(Upload a skill) → hwpx.zip 고르기
  3. 목록에 hwpx가 생기고 켜짐이면 성공

📌 이 스킬은 공개 프로젝트 github.com/Canine89/hwpxskill 입니다. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있어요. 올리기가 실패하면 개별 점검 시간에 강사와 함께 합니다.

hwpx 스킬로 마을 안내문을 한글 문서로 만들어줘. 공문서 모양으로. 제목: [도순마을 김장 나눔 잔치 안내] 내용: [2026년 12월 5일(토) 오전 9시~오후 2시, 도순 마을회관 앞마당(비 오면 2층), 주민 누구나, 준비물 고무장갑·앞치마·김치통, 신청은 11월 27일(금)까지 부녀회장께] 일시·장소·대상·준비물·신청은 표로, 끝에 '도순마을회' 이름을 넣어줘.

X — 내려받은 zip을 그대로 올립니다.

클로드가 추천한 식당은 모두 실제로 있는 곳이다.

X — 문 닫았거나 지어낸 곳일 수 있습니다. 웹 검색 + 지도앱으로 확인!
