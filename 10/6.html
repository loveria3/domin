1단계 — 올리고 · 옮기고 · 저장하기

오늘의 핵심30분

큰 프롬프트 하나로 한 번에 보냅니다. 이름부터 내 이름으로 고치세요.

프롬프트 1 — PDF 편집기 만들기
PDF를 다루는 웹앱을 아티팩트로 만들어줘. 제목은 [강지애]의 PDF 편집기 라고 해줘. [올려서 보기] - 컴퓨터에 있는 PDF 파일을 화면 위로 끌어다 놓으면 올라가게 해줘. 여러 개를 한꺼번에 놓아도 되게. - 눌러서 파일을 고르는 것도 되게 해줘. - 올린 PDF의 페이지를 그림으로 죽 늘어놓아 보여줘. - 파일별로 칸을 나누지 말고, 모든 페이지를 하나의 목록에 이어서 늘어놓아 줘. 번호도 전체를 통틀어 1번부터. - 어느 파일에서 온 페이지인지는 그림 아래에 작은 글씨로 적어줘. [순서 바꾸고 빼기] - 페이지를 끌어다 놓으면 순서가 바뀌게. 다른 파일에서 온 페이지끼리도 바뀌어야 해. - 끌기가 어려운 사람을 위해 페이지마다 앞으로 · 뒤로 단추도 넣어줘. - 페이지마다 빼기 단추, 그리고 되돌리기 단추 하나. [합쳐서 저장] - 화면에 있는 페이지를 전부 합쳐서 PDF 한 개로 저장하게 해줘. - 저장하기 전에 파일 이름을 내가 적을 수 있게 해줘. 글씨는 크게, 단추에는 무슨 일이 일어나는지 한글로 적어줘.

확인 — 샘플 01(파랑 3장) + 02(주황 2장)

  • 제목에 내 이름이 떴는지
  • 01 · 02를 한꺼번에 끌어다 놓기 → 다섯 장이 한 줄로 보이면 성공
  • 주황 1페이지를 맨 앞으로 → 색이 섞이면 제대로 된 것 🎨
  • 한 장 빼기 → 되돌리기 → 이름 "내연습"으로 저장 → 열어서 순서 확인

💾 저장 ① — 아티팩트 오른쪽 위 다운로드.

안 될 때만 ① — 화면이 하얗게 나오면
화면이 하얗게 나와. 무슨 문제인지 찾아서 고쳐줘. PDF를 읽는 부분은 pdf.js 와 pdf-lib 을 cdnjs 에서 불러오는 방식으로 다시 만들어줘.
안 될 때만 ② — 파일끼리 순서가 안 바뀌면
지금은 같은 파일 안에서만 순서가 바뀌어. 올린 모든 페이지를 하나의 목록으로 합쳐서 관리해줘. 그래야 어느 파일에서 왔든 서로 자리를 바꿀 수 있어. 지금 있는 기능은 그대로 두고 이 부분만 고쳐줘.

무슨 뜻인지 몰라도 괜찮습니다 — 고장 났을 때만 쓰는 구급약입니다 💊

8분
프롬프트 2 — 돌리기
거꾸로 들어간 페이지를 바로 세우는 기능을 더해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 페이지마다 돌리기 단추. 한 번 누를 때마다 오른쪽으로 90도씩. - 미리보기 그림도 같이 돌아가고, 저장할 때도 돌린 그대로 저장되게.
  • 샘플 03 영수증 거꾸로 → 돌리기 두 번 → 저장 → 열어서 확인

저장한 파일이 그대로 거꾸로면 — "미리보기는 도는데 저장한 파일은 그대로야. 저장할 때도 돌아가게 고쳐줘." 💾 저장 ②

12분

폰으로 찍은 서류를 제출용 PDF로! 실제로 제일 많이 쓰게 될 기능입니다.

프롬프트 3 — 사진 넣기
사진도 넣을 수 있게 해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 스마트폰으로 찍은 사진 파일을 끌어다 놓으면 PDF 한 페이지로 들어가게. - 사진은 A4 한 페이지 가운데에, 원래 비율 그대로. - 사진 페이지도 순서 바꾸기, 빼기, 돌리기가 똑같이 되게.
  • 샘플 04 계약서 앞장 + 05 뒷장 + 06 관리비고지서 사진 → 한 파일로 저장 (3페이지면 성공)
  • 여유가 있으면 — 폰으로 아무 종이나 찍어 카톡 '나와의 채팅' → 컴퓨터에서 받아 올리기

💾 저장 ③

4단계 — 여러 개로 나누기 → 완성!

10분
프롬프트 4 — 나누기
긴 자료를 여러 개로 나누는 기능을 더해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 몇 개로 나눌지 내가 숫자로 정하게. - 딱 나눠지지 않으면 앞의 파일부터 한 페이지씩 더 가져가게. - 파일 이름을 적으면 뒤에 번호가 붙게. 안내책자 라고 적으면 안내책자 1, 안내책자 2. - 나누기 전에 '여덟 페이지를 세 개로 나눕니다' 처럼 미리 알려줘. - 나온 파일은 압축 파일 하나로 묶어서 받아지게.
  • 샘플 09 안내책자 8페이지 → 4개로 나누기 → 2페이지씩 네 개
  • 3개로도 → 3 · 3 · 2 페이지
안 될 때만 — 압축 파일이 안 만들어지면
여러 개를 하나의 압축 파일로 묶는 게 안 돼. JSZip 을 cdnjs 에서 불러와서 고쳐줘.

💾 저장 ④ — 오늘의 완성본! 🎉
