지난주 홍보물 올려 내 주소 만들기

12분

4차시에 만든 홍보물을 올려서 ○○○.vercel.app 주소를 받습니다. 오늘 마지막에 앱을 올릴 때도 똑같이 합니다.

홍보물 파일 찾기

  1. 4차시에 아티팩트에서 다운로드한 .html 파일 찾기 (보통 다운로드 폴더)
  2. 파일이 없으면 — claude.ai 왼쪽 대화 목록에서 지난주 대화 열기 → 아티팩트 오른쪽 위 다운로드
  3. 받은 파일 이름을 index로 바꾸기 (첫 화면 파일은 index.html — 2차시 약속!)

대화도 파일도 없으면 → 감귤 예시 홍보물 받기 (이름이 이미 index.html입니다)

올리고 주소 받기

  1. vercel.com/drop ↗ → index.html을 가운데로 끌어다 놓기
  2. Project Name에 영어 이름 (예: jiae-gyul) → Deploy
  3. Continue to Project → Domains 아래 ○○○.vercel.app이 내 홍보물 주소 (위쪽 긴 주소 말고)
  • 주소를 카톡 나와의 채팅으로 보내 폰에서 열리는지
  • 패들렛에 "6차시 홍보물 — [내 이름]" + 주소 올리기 · 주소는 메모해 두기 (10번에서 또 씁니다)

⚠ 지난주 브라우저에서 📷 사진 넣기로 끼운 사진은 파일에 저장되지 않아 빈칸으로 보일 수 있어요. 사진까지 보이게 하려면 지난주 대화에 ＋로 사진을 올리고 아래 부탁을 보낸 뒤, 새로 받은 파일로 다시 올리세요.

사진이 빈칸이면 — 지난주 대화에
같이 올린 사진을 사진 자리에 처음부터 넣은 html 파일로 다시 만들어줘. 나머지는 그대로 둬.

⚠ 올린 홍보물은 주소를 아는 누구나 봅니다. 진짜 전화번호·계좌번호가 들어 있으면 지우고 올리세요.

PDF 올려서 보기 — 뼈대 만들기

오늘의 핵심15분

오늘은 기능을 하나씩 더해 갑니다. 프롬프트는 전부 🔍 크게 보기를 누르고 직접 쳐 보세요 ⌨ 한 개 보내고 → 되는지 보고 → 다음 것.

① 올려서 보기

프롬프트 1-① — 올려서 보기
PDF 편집기를 아티팩트로 만들어줘. 제목은 [강지애]의 PDF 편집기. - PDF 파일을 화면에 끌어다 놓거나 눌러서 고르면 올라가게. - 올린 PDF의 페이지를 그림으로 죽 늘어놓아 보여줘. - PDF를 읽는 부분은 pdf.js 를 cdnjs 에서 불러와서 써줘. - 글씨는 크게, 단추 이름은 한글로.
  • 제목에 내 이름이 떴는지
  • 샘플 01(파랑 3장)을 끌어다 놓기 → 세 장이 그림으로 보이면 성공

② 여러 파일을 한 줄로

프롬프트 1-② — 한 줄로 모으기
PDF 여러 개를 한꺼번에 올릴 수 있게 해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 파일별로 칸을 나누지 말고 모든 페이지를 한 줄로 이어서 보여줘. - 번호도 전체를 통틀어 1번부터.
  • 샘플 01 + 02(주황 2장)를 한꺼번에 끌어다 놓기 → 다섯 장이 1~5번으로 한 줄에

③ 어느 파일에서 왔는지

프롬프트 1-③ — 파일 이름 표시
페이지 그림 아래에 어느 파일에서 온 페이지인지 작은 글씨로 적어줘. 나머지는 그대로 둬.
  • 그림 아래에 01…, 02… 파일 이름이 작은 글씨로 보이는지

💾 저장 ① — 아티팩트 오른쪽 위 다운로드

안 될 때만 — 화면이 하얗게 나오면
화면이 하얗게 나와. 무슨 문제인지 찾아서 고쳐줘. PDF를 읽는 부분은 pdf.js 를 cdnjs 에서 불러오는 방식으로 다시 만들어줘.

무슨 뜻인지 몰라도 괜찮습니다 — 고장 났을 때만 쓰는 구급약입니다 💊

순서 바꾸기

10분
프롬프트 2 — 순서 바꾸기
페이지 순서를 바꾸는 기능을 더해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 페이지를 끌어다 놓으면 순서가 바뀌게. 다른 파일에서 온 페이지끼리도 바뀌어야 해. - 끌기가 어려운 사람을 위해 페이지마다 앞으로, 뒤로 단추도 넣어줘. - 순서가 바뀌면 번호도 새로 매겨줘.
  • 주황 1페이지를 맨 앞으로 → 파랑·주황 색이 섞이면 성공 🎨
  • 앞으로 · 뒤로 단추로도 한 칸씩 움직이는지
안 될 때만 — 파일끼리 순서가 안 바뀌면
지금은 같은 파일 안에서만 순서가 바뀌어. 올린 모든 페이지를 하나의 목록으로 합쳐서 관리해줘. 그래야 어느 파일에서 왔든 서로 자리를 바꿀 수 있어. 지금 있는 기능은 그대로 두고 이 부분만 고쳐줘.

💾 저장 ②

합쳐서 PDF 한 개로 저장

오늘의 핵심8분

여기까지 되면 PDF 합치기 사이트가 필요 없습니다.

프롬프트 4 — 합쳐서 저장
화면에 있는 페이지를 PDF 한 개로 합쳐서 저장하는 기능을 더해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 화면에 보이는 순서 그대로, 뺀 페이지는 빼고. - 저장하기 전에 파일 이름을 내가 적을 수 있게. - 저장은 pdf-lib 을 cdnjs 에서 불러와서 써줘.
  • 순서를 바꾸고 한 장 뺀 다음 이름 "내연습"으로 저장
  • 받은 파일을 열어 화면과 같은 순서 · 같은 장수인지

💾 저장 ③ — 쉬는 시간 전 꼭!

거꾸로 된 페이지 세우기

8분
프롬프트 5 — 돌리기
거꾸로 들어간 페이지를 바로 세우는 기능을 더해줘. 앞에서 만든 것은 그대로 두고 이것만 더해줘. - 페이지마다 돌리기 단추. 한 번 누를 때마다 오른쪽으로 90도씩. - 미리보기 그림도 같이 돌아가고, 저장할 때도 돌린 그대로 저장되게.
