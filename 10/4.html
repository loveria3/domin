| 칸 | 앞면 | 속지 | | 왼쪽 | 오시는 길 · 연락처 | 프로그램 소개 | | 가운데 | 기관 소개 | 하루 일과표 | | 오른쪽 | 표지(제목·사진) | 이용 안내 | 잘 읽히는 이유: ① 제목이 크다 ② 칸마다 주제가 하나 ③ 사진과 글이 번갈아 나온다

3단 리플렛 모양으로 만들기

오늘의 핵심20분
프롬프트 5 — 3단 리플렛 (통째로 복사)
위에서 정한 내용으로 3단 접는 리플렛을 아티팩트로 만들어줘. 앞면과 속지를 두 장으로 보여줘. [크기] - 종이는 A4 가로, 세 칸으로 똑같이 나눠줘 - 1장 = 앞면, 2장 = 속지 [앞면 세 칸] - 왼쪽: 찾아오시는 길, 연락처 - 가운데: 소개, 누가 오면 좋은지 - 오른쪽: 표지 (제목을 크게) [속지 세 칸] - 왼쪽: [무엇을 하는지] - 가운데: [하루 흐름 · 시간표] - 오른쪽: [신청 방법] [사진 자리] - 사진이 들어가면 좋을 자리는 연한 회색 네모로 비우고, 안에 '사진: 무엇' 이라고만 적어줘 분위기는 [숲 느낌의 초록색, 따뜻하게].
  • 가로로 긴 두 장이 나왔는지 (앞면 · 속지)
  • 세 칸이 고르게 나뉘었는지
  • 글자가 넘치면 → "글씨를 조금 줄여줘" / 세로로 나오면 → "A4 가로로"

모양이 자꾸 어긋나면 2번의 리플렛 사진을 다시 올리고 "이 사진처럼 만들어줘"

인쇄용 PDF로 받기

10분
프롬프트 7 — PDF 파일로
이 리플렛을 인쇄용 PDF 파일로 만들어서 내려받게 해줘. A4 가로, 1페이지는 앞면, 2페이지는 속지. 딱 두 장으로. 여백은 0으로 하고, 글자가 가장자리에서 잘리지 않게 해줘.
  • 받은 PDF를 열어 두 장인지, 가로인지 확인
  • 칸이 안 맞으면 → "세 칸을 똑같은 너비로 다시"
  • 인쇄할 때 — 양면 인쇄 · '실제 크기(100%)' 로 해야 접었을 때 맞습니다

Canva에서 진짜 사진 넣기

도전10분

※ 먼저 끝낸 분만 — 집에서 해도 됩니다.

회색 네모에 진짜 사진을 끼웁니다. Canva에서 한글이 깨지지 않도록 글자를 그림으로 굳힌 PDF를 먼저 받습니다.

도전 — Canva용 PDF
이 리플렛을 Canva에 올릴 PDF로 다시 만들어줘. - A4 가로, 두 장, 세 칸 정확히 3등분, 여백 0 - 글자는 전부 이미지로 바꿔서 넣어줘 (Canva에서 한글이 안 깨지게) - 단, 페이지 전체를 이미지 한 장으로 합치지는 마 - 사진 자리는 연한 회색 네모로, 이미지가 아니라 PDF 도형으로 그려줘 - 회색 네모 위에는 어떤 이미지도 겹치지 않게 해줘
  1. canva.com → 업로드 → 받은 PDF 올리기
  2. 왼쪽 요소 → 사진 검색(예: 숲길) 또는 내 사진 업로드
  3. 사진을 회색 네모 한가운데로 끌어다 놓기 → 쏙 들어갑니다
  4. 공유 → 다운로드 → PDF 인쇄용
