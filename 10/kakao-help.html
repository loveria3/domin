2차시 · 도움말

클로드와 카카오톡 연결하기

PlayMCP에 먼저 담고 → 클로드에 연결합니다. 위에서부터 한 단계씩, 막히면 그 단계의 😥 빨간 줄을 누르세요.

?

왜 카톡에 바로 연결하지 않고 PlayMCP를 거치나요?

클로드는 '커넥터'라는 정해진 단자로만 다른 서비스와 연결됩니다. 카카오톡 앱에는 이 단자가 없어서, 카카오가 따로 만든 연결 창구가 PlayMCP입니다.

🤖 클로드→🧰 PlayMCP 도구함→💬 내 카카오톡

🔌 클로드는 플러그, 카카오톡은 콘센트 없는 벽. 카카오가 멀티탭(도구함)을 만들어 두었습니다. 그래서 순서가 ① 멀티탭에 '카톡 나챗방'을 꽂고 → ② 클로드 플러그를 멀티탭에 꽂기예요. 카톡 비밀번호는 클로드에 주지 않고, 카카오 창에서 동의만 누릅니다.

💰 무료입니다. 클로드 무료 계정에서도 됩니다.

PART 1 · PlayMCP에서 준비 (카카오 사이트)

1

PlayMCP 가입

새 탭에서 playmcp.kakao.com ↗ → 오른쪽 위 로그인 → 카카오 계정 로그인 → 모두 동의합니다 → 시작하기

✔ PlayMCP 첫 화면이 보이면 2단계로

폰으로 확인하라고 나와요
폰 카카오톡에 온 로그인 확인 알림에서 확인. 폰을 옆에 두세요.
카카오 아이디·비밀번호를 모르겠어요
폰 카카오톡 → 설정(톱니) → 카카오계정에서 내 계정을 볼 수 있습니다. 또는 로그인 창의 QR코드 로그인 → 폰 카톡으로 QR 찍기.
가입이 안 된다고 나와요
카카오 계정에 본인 인증과 대표 이메일이 있어야 합니다(만 14세 이상). 폰 카톡 → 설정 → 카카오계정에서 등록 후 다시.
2

★ 도구함에 '카카오톡 나챗방' 추가

  1. 위쪽 메뉴 도구함 (바로가기: playmcp.kakao.com/toolbox ↗)
  2. ＋ MCP 추가하기 누르기
  3. 목록에서 카카오톡 나챗방(노란 TALK 아이콘) → 추가 → 추가됨으로 바뀜

처음엔 비어 있어요 (추가한 MCP 0/10). MCP 추가하기를 누릅니다.

✔ 카카오톡 나챗방 카드가 생기고 1/10, 스위치가 파란색이면 성공!

⚠ 오른쪽 도구함 URL · 복사하기는 쓰지 않습니다. 클로드에서는 4단계처럼 목록에서 골라 연결해요.

카드 스위치가 회색이에요
눌러서 파란색(켜짐)으로 바꾸세요. 꺼져 있으면 클로드가 이 도구를 못 씁니다.

💡 처음엔 이것 하나만 담으세요. 모르는 사람이 만든 도구까지 담으면 클로드가 헷갈리고 내 정보가 새 나갈 수 있습니다.

PART 2 · 클로드에 연결 (클로드 사이트)

3

클로드에서 PlayMCP 찾기

왼쪽 아래 내 이름 → 설정 → 커넥터 (사이드바 사용자 지정 아래) → 위쪽 탐색 탭 → 검색창에 play

✔ PlayMCP가 보이면 누르기

'커넥터' 메뉴가 안 보여요
왼쪽 메뉴에서 '커넥터'라는 글자를 찾으세요. 폰 앱보다 크롬에서 claude.ai로 하는 게 가장 쉽습니다.
검색해도 PlayMCP가 안 나와요
내 커넥터 탭이 아니라 그 옆 탐색 탭인지 확인하세요. 회사(Team) 계정이면 관리자가 먼저 PlayMCP를 팀에 추가해야 합니다 — 오늘은 개인 계정으로 하세요.
목록에 이미 PlayMCP가 '연결됨'이에요
연결은 끝난 상태입니다. 2단계에서 나챗방을 담았는지만 확인하고 6단계로.
4

Claude에 연결 → 카카오 로그인

PlayMCP 화면에서 Claude에 연결(또는 연결) → 새 창에서 카카오 로그인. 1단계와 같은 카카오 계정이어야 합니다.

✔ 동의 화면이 나오면 5단계로

눌러도 아무 창도 안 떠요
브라우저가 팝업을 막은 것입니다. 주소창 오른쪽 끝 차단 아이콘 → 항상 허용 → 다시 연결.
'커넥터 연결을 완료하시겠습니까?' 창이 떠요
클로드 데스크톱 앱에서 시작하면 브라우저에 이 창이 뜹니다. 내가 방금 시작한 것이면 계속 연결. 내가 하지 않은 연결이면 누르지 말고 닫으세요.
'허용되지 않는 IP 대역' 오류가 나요
주소(URL)를 직접 붙여넣어 만든 커넥터라서 그렇습니다. 그 커넥터를 … → 제거하고, 3단계처럼 탐색 탭의 PlayMCP로 다시 연결하세요.
로그인했는데 빈 화면이에요
그 창을 닫고 클로드에서 연결을 한 번 더. 이미 로그인돼 있어서 바로 동의 화면이 뜹니다.
5

동의하고 돌아오기

Claude에 PlayMCP 연결하기 창에서 권한과 필수 동의를 확인 → 모두 동의 후 계속하기

✔ 연결됨이 뜨면 탭을 닫고 클로드로. 커넥터 목록에 PlayMCP · 연결됨

무엇에 동의하는 건가요?
PlayMCP 계정 확인, 도구함 목록 확인, 도구 사용 권한입니다. 그리고 개인정보 제3자 제공·국외 이전 동의(클로드 회사가 해외에 있어서)가 필수로 붙어 있어요. 각 항목 보기로 펼쳐 읽을 수 있습니다.
창은 닫혔는데 '연결됨'이 안 보여요
클로드 화면 새로고침(F5). 그래도 없으면 3단계부터 다시.

PART 3 · 써 보기

6

대화창에서 PlayMCP 켜기

클로드 새 대화 → 입력창 아래 ＋ → 커넥터 → PlayMCP 스위치가 파란색인지 확인

✔ 켜져 있으면 7단계로

＋ 메뉴에 PlayMCP가 없어요
화면 새로고침 후 새 대화를 여세요. 이미 열려 있던 대화에는 늦게 뜨기도 합니다.
7

보내 달라고 하고 '허용'

먼저 짧게 시험: "빨리 퇴근하자"라고 나챗방에 보내줘 → "도구를 사용할까요?" 창에서 내용 확인 → 허용

✔ 클로드가 "보냈습니다"라고 하면 8단계로. 그다음 교안의 보너스 프롬프트!

"카카오톡으로는 보낼 수 없어요" / 도구를 못 찾아요
  1. 6단계 스위치가 켜져 있는지
  2. 2단계 도구함에 카카오톡 나챗방이 추가됨·파란 스위치인지
  3. 그다음 "PlayMCP 카카오톡 나챗방 도구로 보내줘"라고 다시
글만 써 주고 허용 창이 안 떠요
'보내줘'가 빠지면 글만 씁니다. "방금 글을 나챗방에 보내줘" 한마디 더.
길게 쓴 글이 안 가요 / 잘려요
한 번에 200자까지입니다. "200자 안으로 줄여서 보내줘".
친구나 단톡방에 바로 보내 달라고 해도 되나요?
안 됩니다. 나에게만 보내는 도구예요. 나챗방에서 받은 글을 꾹 눌러 → 전달하세요.
매번 허용 누르기 번거로워요
설정 → 커넥터 → PlayMCP를 열면 도구마다 항상 허용 / 승인 필요 / 차단을 고를 수 있어요. 익숙해지기 전엔 승인 필요로 매번 내용을 확인하세요.
오류가 나거나 '인증이 만료됐다'고 해요
설정 → 커넥터 → PlayMCP 연결 해제 → 다시 연결 (4~5단계).
✓

폰에서 확인

폰 카카오톡 → 나와의 채팅 → 클로드가 보낸 글 확인 → 주소 눌러 열어 보기

'나와의 채팅' 방을 못 찾겠어요
카카오톡 친구 탭 맨 위 내 프로필 → 나와의 채팅.
클로드는 보냈다는데 폰에 없어요
카톡 앱을 껐다 켜기. 그래도 없으면 폰 카톡 계정과 1·4단계 카카오 계정이 같은지 확인하세요.
