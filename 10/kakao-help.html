2차시 · 도움말

클로드와 카카오톡 연결하기

위에서부터 한 단계씩 하세요. 막히면 그 단계의 😥 빨간 줄을 눌러 해결 방법을 보세요.

1 커넥터 찾기2 연결3 카카오 로그인4 동의5 도구 담기 ★6 대화에서 켜기7 보내기·허용8 폰 확인
?

왜 카톡에 바로 연결하지 않고 PlayMCP를 거치나요?

클로드는 '커넥터'라는 정해진 단자로만 다른 서비스와 연결됩니다. 카카오톡 앱에는 이 단자가 없어서, 카카오가 따로 만든 연결 창구가 PlayMCP입니다.

🤖 클로드→🧰 PlayMCP 도구함→💬 내 카카오톡

🔌 클로드는 플러그, 카카오톡은 콘센트 없는 벽. 카카오가 멀티탭(도구함)을 만들어 두었고, 우리는 거기에 '카톡 나에게 보내기'를 꽂아 쓰는 겁니다. 카톡 비밀번호는 클로드에 주지 않고, 카카오 창에서 허용만 누릅니다.

⚠ 가장 많이 막히는 곳은 5단계입니다. 연결은 됐는데 멀티탭이 비어 있으면 아무것도 안 됩니다.

1

클로드에서 PlayMCP 찾기

왼쪽 아래 내 이름 → 설정 → 커넥터 → 커넥터 둘러보기 → 검색창에 PlayMCP (또는 카카오)

✔ 노란색 PlayMCP 카드가 보이면 누르기

'커넥터' 메뉴가 안 보여요
메뉴 이름이 맞춤 설정(Customize) 안에 들어 있을 수 있습니다. 왼쪽 메뉴에서 '커넥터'라는 글자를 찾으세요. 앱보다 크롬에서 claude.ai로 하는 게 가장 쉽습니다.
검색해도 PlayMCP가 안 나와요
직접 주소로 붙이면 됩니다.
  1. 커넥터 화면에서 사용자 정의 커넥터 추가 (Add custom connector)
  2. 이름 PlayMCP, 주소에 아래를 붙여넣고 추가 → 2단계로
https://playmcp.kakao.com/mcp
이미 목록에 PlayMCP가 '연결됨'으로 있어요
연결은 끝난 상태입니다. 5단계(도구 담기)로 바로 가세요.
2

연결 누르기

PlayMCP 화면에서 연결(Connect)을 누르면 새 창이 뜹니다.

✔ 카카오 로그인 창이 열리면 3단계로

눌러도 아무 창도 안 떠요
브라우저가 팝업을 막은 것입니다. 주소창 오른쪽 끝의 차단 아이콘 → 항상 허용 → 다시 연결.
'업그레이드'나 '한도' 안내가 떠요
무료 계정은 사용자 정의 커넥터를 하나만 붙일 수 있습니다. 이미 다른 것을 붙였다면 그것을 … → 제거한 뒤 다시 해 보세요. 그래도 안 되면 오늘은 복사·붙여넣기로 대신합니다.
3

카카오 로그인

카카오 계정(이메일 또는 전화번호)과 비밀번호로 로그인합니다. 주소창이 kakao.com인지 확인하세요.

✔ 동의 화면이 나오면 4단계로

폰으로 확인하라고 나와요
폰 카카오톡에 온 로그인 확인 알림에서 확인을 누르면 컴퓨터 화면이 넘어갑니다. 폰을 옆에 두세요.
카카오 아이디·비밀번호를 모르겠어요
폰 카카오톡 → 설정(톱니) → 카카오계정에서 내 계정 이메일/전화번호를 볼 수 있습니다. 또는 로그인 창의 QR코드 로그인 → 폰 카톡으로 QR 찍기.
로그인했는데 빈 화면이에요
그 창을 닫고 클로드로 돌아가 연결을 한 번 더 누르세요. 이미 로그인돼 있어서 바로 동의 화면이 뜹니다.
4

동의하고 돌아오기

PlayMCP를 처음 쓰면 이용 약관 동의 → 정보 제공 동의가 차례로 나옵니다. 필수 항목에 체크하고 동의하고 계속하기.

✔ 창이 닫히고 클로드 커넥터 목록에 PlayMCP · 연결됨이 보이면 성공

창은 닫혔는데 '연결됨'이 안 보여요
클로드 화면을 새로고침(F5) 하세요. 그래도 없으면 2단계부터 한 번 더.
5

★ 도구함에 '카카오톡 나에게 보내기' 담기

연결만 하고 이 단계를 빼먹는 경우가 제일 많습니다. 멀티탭에 아무것도 안 꽂힌 상태예요.

  1. 새 탭에서 playmcp.kakao.com ↗ → 로그인 (같은 카카오 계정)
  2. 검색창에 카카오톡 → 카카오톡 나에게 보내기(나와의 채팅방) 카드 → 만든 곳이 카카오인지 확인
  3. 도구함에 담기 누르기
  4. 위쪽 도구함 메뉴에 들어가 담긴 것 확인

✔ 클로드 커넥터 화면에서 PlayMCP를 누르면 아래에 도구 이름이 보이면 성공

클로드에서 PlayMCP를 눌렀는데 도구 목록이 비어 있어요
도구함이 비어 있는 것입니다. 위 1~4번을 하세요. 클로드 쪽은 다시 연결할 필요 없습니다.
담았는데 클로드에 아직 안 보여요
  1. 클로드 화면 새로고침(F5)
  2. 새 대화 시작
  3. 그래도 안 되면 커넥터에서 PlayMCP 연결 해제 → 다시 연결
PlayMCP와 클로드에 다른 카카오 계정으로 로그인한 것 같아요
두 곳이 같은 계정이어야 합니다. PlayMCP 오른쪽 위 프로필에서 계정을 확인하고, 다르면 로그아웃 후 3단계에서 쓴 계정으로 다시 로그인해 도구를 담으세요.

💡 처음엔 이 도구 하나만 담으세요. 이것저것 담으면 클로드가 헷갈리고, 모르는 사람이 만든 도구는 내 정보를 가져갈 수 있습니다.

6

대화창에서 PlayMCP 켜기

클로드 새 대화 → 입력창 아래 ＋ → 커넥터 → PlayMCP 스위치가 파란색(켜짐)인지 확인

✔ 켜져 있으면 7단계로

＋ 메뉴에 PlayMCP가 없어요
설정 → 커넥터에서 '연결됨'인지 다시 보고, 화면 새로고침 후 새 대화를 여세요. 이미 열려 있던 대화에는 늦게 뜨기도 합니다.
7

보내 달라고 하고 '허용'

교안의 보너스 프롬프트를 보내면, 보내기 직전 "이 도구를 사용할까요?" 창이 뜹니다. 보낼 내용을 읽고 이번만 허용.

✔ 클로드가 "보냈습니다"라고 하면 8단계로

"카카오톡으로는 보낼 수 없어요"라고 해요
대개 6단계 스위치가 꺼져 있습니다. 켠 뒤 이렇게 다시 말해 보세요: "PlayMCP의 카카오톡 나에게 보내기 도구로 보내줘."
글만 써 주고 허용 창이 안 떠요
'보내줘'를 빠뜨리면 글만 씁니다. "방금 글을 카카오톡 나와의 채팅방에 보내줘" 한마디 더.
카카오 동의 창이 또 떠요
메시지 보내기 권한을 처음 쓸 때 한 번 더 묻는 것입니다. 동의하고 한 번 더 보내 달라고 하세요.
'항상 허용'은 눌러도 되나요?
누르면 다음부터 묻지 않고 바로 보냅니다. 익숙해지기 전엔 이번만 허용으로 매번 내용을 확인하세요.
오류가 나거나 '인증이 만료됐다'고 해요
설정 → 커넥터 → PlayMCP → 연결 해제 → 다시 연결 (3~4단계 다시).
✓

폰에서 확인

폰 카카오톡 → 나와의 채팅 → 클로드가 쓴 글 확인 → 주소 눌러 열어 보기

'나와의 채팅' 방을 못 찾겠어요
카카오톡 친구 탭 맨 위 내 프로필 누르기 → 나와의 채팅. 채팅 목록 위쪽에 고정되어 있기도 합니다.
클로드는 보냈다는데 폰에 없어요
카톡 앱을 껐다 켜기. 그래도 없으면 폰 카톡과 3단계에서 로그인한 카카오 계정이 같은지 확인하세요.
