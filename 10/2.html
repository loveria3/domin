내 컴퓨터로 내려받아 열어 보기

7분
  1. 아티팩트 오른쪽 위 다운로드(↓) 단추 → 파일 받기
  2. 다운로드 폴더에서 받은 파일을 더블클릭 → 크롬에서 열리면 성공
  3. 파일 이름을 index.html 로 바꾸기 (오른쪽 단추 → 이름 바꾸기)
왜 index인가요? — 인터넷에서 "이 주소의 첫 화면"이라는 약속된 이름입니다. 이렇게 해 두면 주소 뒤에 아무것도 안 붙여도 바로 열립니다.

"html이 안 보여요" → 확장자가 숨겨진 것입니다. index 까지만 바꾸면 됩니다.

다운로드가 안 되면 → 위의 예시 파일 내려받기로 받아서 오늘 연습을 이어 가세요.

처음 가입하면 나만 보이게(비공개) 올라갑니다. 그대로 두면 다른 사람에겐 로그인 화면이 뜹니다.

  1. 내 사이트 이름 옆 🔒 Private 확인 → 아래 Make public 누르기
  2. 작은 창에서 Public 확인 → Make public 한 번 더
  3. Your project is public이 나오면 끝 — 폰에서 내 주소 열어 보기

마무리

X — "좌우 슬라이드로 바꿔줘. 내용은 그대로 둬." 처럼 한 가지씩 말하면 됩니다.

인터넷에 올린 발표자료는 주소만 알면 누구나 볼 수 있다.

O — 그래서 편리하지만, 개인정보는 넣지 않습니다.

파일 이름을 index.html 로 하면 주소 뒤에 아무것도 안 붙여도 첫 화면으로 열린다.

O — index는 "첫 화면"이라는 약속된 이름입니다.
