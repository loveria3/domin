2차시 · 도움말

오른쪽에 아티팩트가 안 보일 때

"만들어줘" 했는데 오른쪽에 아무것도 안 뜨면, 아래 세 번만 누르면 됩니다.

1

왼쪽 아래 내 이름 누르기

클로드 화면 왼쪽 맨 아래에 내 이름(또는 첫 글자 동그라미)이 있습니다. 누르면 작은 메뉴가 펼쳐지고, 그중 설정을 누릅니다.

그림 예시
＋ 새로 생성
최근 대화
강 · 내 이름
이메일 주소
설정
언어
도움말
로그아웃
2

설정에서 기능 누르기

설정 화면 왼쪽에 여러 칸이 있습니다. 그중 기능을 누릅니다.

그림 예시
일반
계정
개인정보
기능
커넥터
← 왼쪽에서 '기능'을 누르세요
3

아티팩트 스위치 켜기

기능 화면에서 아티팩트 스위치를 찾아 켜짐(초록)으로 바꿉니다. 같은 화면의 코드 실행 및 파일 만들기도 켜 두세요 — 3·4차시에 엑셀과 PDF를 받을 때 필요합니다.

그림 예시
아티팩트
코드 실행 및 파일 만들기

실제 화면의 글자·위치는 클로드 업데이트에 따라 조금 다를 수 있습니다.

!

켰는데도 안 보이면

  1. 클로드 창으로 돌아와 새로고침(F5)
  2. 부탁 끝에 "아티팩트로 보여줘" 한마디 더 붙여 다시 보내기
  3. 답 안에 작은 카드(제목 상자)가 생겼다면 그걸 눌러 열기
  4. 창이 좁으면 오른쪽이 접혀 있을 수 있음 → 크롬 창을 최대화
그래도 안 되면 손을 들어 주세요. 옆 사람 화면으로 먼저 따라 하고, 강사가 바로 도와드립니다.
