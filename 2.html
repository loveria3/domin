클로드가 정리하는 걸 보기

12분

오늘의 두 번째 마법. 방금 쏟아낸 글 바로 다음 줄에 이 한 문장을 붙이세요. 클로드가 흩어진 말을 항목별로 나누고, 빠진 건 되물어 채웁니다.

정리를 시키는 한 문장 — 오늘의 핵심
위에 내가 두서없이 말한 걸 자기소개 발표자료용으로 정리해줘. 기본정보 · 살아온 이야기 · 가족 · 취미 · 요즘 근황으로 항목을 나눠서 보기 좋게 만들어줘. 빠진 게 있으면 나한테 하나씩 물어봐줘.

화면에서 이런 변화가 일어납니다 — 이걸 같이 봅니다.

정리 전 · 내가 쏟아낸 것
63년생, 대구 산다, 애들 둘 결혼, 손주 셋, 은행 다니다 퇴직, 텃밭, 등산, 지난달 지리산, 요즘 클로드 배우는 중… (뒤죽박죽 한 덩어리)
→
정리 후 · 클로드가 나눈 것
기본정보1963년생 · 대구 거주
살아온 이야기은행 근무 후 퇴직
가족자녀 둘(모두 결혼) · 손주 셋
취미등산 · 텃밭 가꾸기
요즘 근황지난달 지리산 산행 · 클로드 학습 중

여기서 클로드는 세 가지를 합니다 — 흩어진 정보를 분류하고, 빠진 항목을 되묻고, 발표에 맞는 형태로 재구성. 이게 "스스로 파악하고 정리한다"의 실체입니다.

클로드가 되물으면 편하게 대답만 하세요. 예: "은행에서 무슨 일 하셨어요?" → "창구 업무 오래 했어."

고치고 · 서식 다듬기

15분
내용 고치기
고쳐줘. ① [몇 번째] 장을 [이렇게] 바꿔줘. ② 지어낸 날짜 · 나이 · 장소는 [확인 필요] 라고 표시해줘. ③ 글이 너무 많은 장은 세 줄로 줄여줘. 고친 파일을 다시 내려받게 해줘.

실제로는 이렇게 씁니다. 어려운 용어 몰라도 됩니다 — 눈에 보이는 대로, 어디가 이상한지만 짚어 주면 클로드가 알아듣습니다.

실전 예시 — 화면 보면서 그대로 말하기
지금 슬라이드마다 번호랑 글자가 세로로 안 맞아 보여. 그리고 마지막 장의 ["이웃들과~"] 문구가 가운데 정렬이 안 돼 있어. 이 두 군데 맞춰줘. 그리고 전체적으로 내용이 좀 비어 보여. 내용에 어울리게 더 채워줘. 고친 파일을 다시 내려받게 해줘.

"세로로 안 맞아 보여" "가운데가 안 돼 있어" 처럼 느낀 대로 말하면 됩니다. 한 번에 여러 군데를 말해도 되고, "[3장] 만" 처럼 콕 집어도 됩니다.

"예쁘게 해줘"는 매번 다르게 나옵니다. 숫자와 색 이름으로 말하세요.

서식 한 번에 — 깔끔하고 세련되게
발표자료를 아래 느낌으로 깔끔하고 세련되게 다시 다듬어줘. [전체 분위기] - 차분하고 고급스러운 느낌으로, 화려하지 않게 - 여백을 넉넉하게 두고, 요소는 왼쪽으로 가지런히 정렬 [색] - 바탕은 흰색, 기본 포인트 색은 [남색] 계열, 글자는 진한 회색 - 포인트가 되는 요소(소제목, 제목 아래 선)는 [로즈핑크] 계열로 통일 - 색은 이 범위 안에서만 (흰색 / 남색 / 진회색 + 포인트 핑크 1곳) [글씨] - 맑은 고딕으로 통일, 어른들이 보기 편하게 큼직하게 - 제목은 크고 굵게, 본문은 24포인트 이상, 줄 간격은 넉넉하게 - 한 장에 항목은 3개까지 [짜임새] - 화면 비율 16:9 - 모든 장의 제목 위치와 여백을 똑같이 맞춰 통일감 있게 - 제목 아래에 얇은 선 하나로 은은하게 포인트 (로즈핑크) - 오른쪽 아래에 쪽 번호 [항목 표시] - 각 항목은 대시(-)가 아니라 남색 원형 번호(①②③ 형태의 숫자 배지)로 표시 - 번호와 텍스트 사이, 항목과 항목 사이 간격을 넉넉하게 두어 답답하지 않게 [배경] - 밋밋하지 않도록, 남색을 옅게 쓴 원형과 큰 슬라이드 번호 워터마크를 배경 장식으로 넣을 것 - 배경 장식은 흐릿한 톤으로, 사진 자리나 본문 내용과 겹치지 않는 위치에 배치 고친 파일을 다시 내려받게 해줘.

지어낸 내용이 섞입니다. 사실 확인은 내가. 한 번에 다 안 되면 안 바뀐 것만 다시 말하면 됩니다.

내 소개 웹페이지(HTML) 만들기

15분

발표자료(.pptx)만 만드는 게 아닙니다. 같은 내용을 웹페이지 한 장으로도 만들 수 있어요. 지금 보고 있는 이 안내문 같은 화면이 바로 클로드가 만든 HTML 파일입니다. 나도 똑같이 만들 수 있습니다.

내 소개 웹페이지 만들기 — 모양까지 정해서
방금 정리한 내 소개를 웹페이지(HTML) 한 장으로 만들어줘. [상단 프로필 영역] - 카드 하나로 감싸고, 배경은 옅은 남색 톤 그라데이션(연한 회색빛 → 흰색)을 은은하게 - 카드 우상단에 옅은 남색 원형 장식을 살짝 겹쳐 넣어 밋밋하지 않게 - 이름 위에는 작은 남색 알약(pill) 모양 라벨 칩으로 "자기소개" 표시 - 사진 자리는 사각형 점선 테두리 박스로, 안에 작은 카메라 아이콘 + "사진 자리" 글자 - 카드 맨 아래에는 얇은 남색 선으로 마무리 [나머지 항목 카드] - 연한 회색 배경(#f7f8fa) 위에 흰색 카드로 항목을 구분 - 카드는 얇은 테두리 + 왼쪽에 남색 포인트 선 - 카드 제목 앞에는 남색 원형 숫자 배지(①②③...) - 정보성 항목(기본정보)은 표(table) 형식, 나머지는 점 목록 [공통] - 맑은 고딕, 여백과 줄 간격 넉넉하게, 색은 흰색·연회색·남색 범위 안에서만 - 하나의 HTML 파일로, 휴대폰에서도 잘 보이게(반응형) 만들 것
  • 내려받은 파일을 두 번 눌러 웹 브라우저에서 열어보기
  • 사진 자리에 넣고 싶으면 — "[사진 자리] 에 이 사진 넣어줘" 하고 사진을 올리기

색이나 모양을 바꾸고 싶으면 — "포인트 색을 초록으로", "카드 사이 간격을 더 넓게" 처럼 한 줄씩 말하면 됩니다. .pptx와 달리 링크로 공유하거나 휴대폰으로 바로 보여주기 좋습니다.

나만의 스킬 만들기

스킬10분

1번에서 구경만 했던 그 설명서를, 이번엔 내가 만듭니다. 좋은 소식 — 방금 만든 걸 클로드가 이미 기억하고 있어서 길게 적을 필요가 없습니다.

오늘 방식을 저장하기 — 이렇게 짧게
방금 만든 발표자료랑 웹페이지가 마음에 들어. 이 방식이랑 서식 그대로 다음에도 쓸 수 있게 두가지를 동시에 만들수 있는 스킬로 만들어줘. 이름은 [mypptx-set]. 오늘 만든 이 발표자료와 웹페이지를 예시로 함께 넣어줘.

이렇게 짧아도 되는 이유 — 같은 대화 안이라 클로드가 방금 만든 서식 (로즈핑크 포인트 발표자료 · 남색 웹페이지)을 그대로 기억하기 때문입니다. "예시로 함께 넣어줘" 한 줄이 핵심 — 오늘 결과물을 견본으로 저장해 둡니다.

단, 새 대화에서 스킬을 만들면 클로드가 오늘 걸 모릅니다. 그때는 아래를 펼쳐 규칙을 적어 주세요.

규칙을 직접 적어 두고 싶다면 — 전체 서식(발표자료 · 웹페이지)

새 대화에서 만들거나, 규칙을 글로 남겨 두고 싶을 때 씁니다. 오늘 맞춘 서식 그대로예요.

전체 서식까지 적은 버전
오늘 한 방식이 마음에 들어. 다음에도 똑같이 되게 스킬로 만들어줘. 이름은 [내 발표자료]. [방식] - 두서없이 말하면 먼저 항목별로 정리하고, 빠진 건 되물어 채운다 - 그 다음 슬라이드 6장(도입 1 · 본문 4 · 마무리 1)으로 만든다 - 제목 1줄, 내용 3줄 이내, 친근한 말투, 사진 자리는 비워 둔다 [발표자료 서식] - 16:9, 맑은 고딕, 여백 넉넉하게, 요소는 왼쪽 정렬 - 바탕 흰색 · 글자 진회색 · 기본 포인트 [남색], 소제목과 제목 아래 선은 [로즈핑크] - 제목은 크고 굵게, 본문 24pt 이상, 한 장에 항목 3개까지 - 각 항목은 남색 원형 숫자 배지(①②③)로 표시 - 배경에 옅은 남색 원형과 큰 슬라이드 번호 워터마크를 흐릿하게, 오른쪽 아래 쪽 번호 [웹페이지(HTML) 서식] - 상단 프로필: 옅은 남색 그라데이션 카드 + 우상단 원형 장식 + "자기소개" 알약 라벨, 사진 자리는 점선 박스(카메라 아이콘), 아래 얇은 남색 선 - 항목 카드: 연회색 배경 위 흰 카드, 왼쪽 남색 포인트 선, 제목 앞 남색 원형 숫자 배지, 기본정보는 표·나머지는 점 목록 - 맑은 고딕, 여백 넉넉, 색은 흰색·연회색·남색 범위, 하나의 HTML 파일·반응형 오늘 만든 발표자료와 웹페이지를 예시로 함께 넣고, 파워포인트 파일과 html 파일로 각각 저장해줘.
① 저장파일이 만들어지면 저장을 누릅니다
② 켜기설정 → 기능 → 스킬 에서 방금 만든 것을 켭니다
③ 확인새 대화에서 "내 방식대로 발표자료 만들어줘" 라고 해 봅니다
스킬이 어렵게 느껴지면 — 더 쉬운 방법

2번에서 만든 내 방 설명란에 같은 규칙을 붙여도 됩니다. 방 안 대화에는 똑같이 적용됩니다.

점검하고 · 집에서

8분
점검
완성된 발표자료를 점검해줘. 맞춤법, 글이 너무 많은 장, 빠진 정보를 목록으로 알려줘.
시간이 남으면 — 한 번 더 만들기 · 3장짜리, 오늘 배운 클로드로 복습

이번엔 주제를 클로드 그 자체로 해 봅니다. 화면의 메뉴들이 각각 무슨 기능인지 정리하는 3장짜리를 만들면, 방금 배운 방식(쏟아내기 → 정리)도 다시 익히고 클로드 사용법 복습까지 한 번에 됩니다.

한 번에 — 클로드 메뉴 기능 정리 (3장)
나는 지금 클로드를 배우고 있어. 클로드 화면의 메뉴마다 어떤 기능인지 정리해서 3장짜리 발표자료로 만들고 싶어. 내가 본 메뉴는 [새 대화, 프로젝트, 검색, 설정] 이야. 빠진 메뉴나 기능이 있으면 네가 채워줘. - 1장: 클로드가 뭔지 한 줄 소개 + 화면 전체 모습 - 2장: 메뉴별 기능 (메뉴 이름 + 한 줄 설명) - 3장: 초보자가 꼭 알아야 할 것 3가지 쉬운 말로, 장마다 제목 1줄과 내용 3줄 이내. 파워포인트 파일로 만들어줘.

메뉴 이름이 가물가물해도 됩니다. 아는 것만 적고 나머지는 클로드가 채웁니다. 화면을 보며 "이 메뉴는 뭐야?" 하고 물어봐도 됩니다.

숙제 — 쏟아내기부터 다시 해 보기
[우리 동네 / 내 취미 / 가족 여행 추억] 에 대해 생각나는 대로 다 말할게. (여기에 두서없이 쏟아내기) 이걸 항목별로 정리해서 슬라이드 5장짜리 발표자료로 만들어줘. 파워포인트 파일로.

숙제는 새 대화에서. 오늘과 같은 형식으로 나오면 스킬이 잘 만들어진 것입니다. 다음 시간 준비물 — 가고 싶은 여행지 한 곳. 내 방에서 시작 잊지 마세요.

1. 정리하려 애쓰지 말고 두서없이 쏟아낸다 — 정리는 클로드 몫

2. 클로드는 흩어진 말을 분류하고 · 되묻고 · 재구성한다

3. 정리된 내용을 그대로 발표자료(.pptx)로 옮긴다

4. 디자인은 "예쁘게"가 아니라 숫자와 색 이름으로

5. 만드는 건 AI, 사실 확인은 나

덧붙임 — 왜 "쏟아내기"부터 하나요?

이미 깔끔하게 정리해서 넣으면 클로드가 할 일이 없어 보입니다. 반대로 두서없이 넣을수록 정리 능력이 눈에 확 들어옵니다.

클로드가 되물으면 어떻게 하나요?

편하게 대답만 하면 됩니다. "은행에서 무슨 일 하셨어요?" 하고 물으면 "창구 업무요" 처럼요. 내가 질문을 만들 필요가 없다는 게 이 방식의 편한 점입니다.

지어낸 내용이 들어가면요?

클로드가 비어 있는 곳을 그럴듯하게 채우기도 합니다. 그래서 6번에서 날짜·나이·장소는 [확인 필요] 로 표시하게 하고, 사실 확인은 내가 합니다.

프롬프트 · 내 방 · 스킬, 뭐가 다른가요?

얼마나 오래 남는지가 다릅니다. 프롬프트는 이번 한 번, 내 방은 그 방 안에서 계속, 스킬은 모든 대화에서 계속. 오늘은 "쏟아내면 정리해 발표자료로" 라는 방식을 스킬로 남겼습니다.
