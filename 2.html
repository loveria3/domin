아티팩트 — 화면에 바로 나오는 결과물

8분

프롬프트 1 — 맛보기: 내 기분 날씨 카드
오늘 내 기분을 날씨 예보처럼 보여 주는 카드를 아티팩트로 만들어줘. 내 기분은 [퇴근해서 조금 피곤하지만 설렘] 이야. 날씨 그림, 기온 대신 '기분 온도', 한 줄 예보를 넣어줘. 귀엽게.
☁️ → 🌤 오늘의 기분 날씨: 구름 조금, 저녁부터 맑음 기분 온도 23℃ · 설렘 지수 80% "피곤 구름은 곧 걷히고 새로운 배움의 햇살이 들겠습니다"
  • 오른쪽에 카드가 떴는지 확인
  • "더 귀엽게" · "색을 분홍으로" 한마디 해 보기

⚠ 오른쪽에 아무것도 안 뜨면 — 왼쪽 아래 내 이름 → 설정 → 기능에서 아티팩트가 켜져 있는지 확인하세요.

웹 발표자료 만들기

오늘의 핵심25분

파란 글씨 네 군데만 고쳐서 보내세요. 나머지 조건은 그대로 두세요 — 그래야 뒤에서 인터넷에 올리기 쉽습니다.

프롬프트 3 — 웹 발표자료 (통째로 복사)
너는 발표자료를 잘 만드는 디자이너야. [한라산 아래 걷기 동호회 '느영나영' 소개] 발표자료를 웹페이지로 만들어줘. 듣는 사람은 [새로 들어올 회원들] 이야. [내용] - 모두 8장. 1장은 표지, 8장은 마무리 인사 - 꼭 넣을 내용: [매주 토요일 아침 모임, 회비 월 1만 원, 올해 다녀온 오름 5곳] - 한 장에 글은 세 줄 이내, 큰 글씨로 [모양] - 한 화면에 한 장씩 보이고, 화면 양쪽에 큰 화살표 단추로 넘기게 해줘 - 키보드 왼쪽·오른쪽 방향키로도 넘어가게 - 오른쪽 아래에 '3 / 8' 처럼 쪽 번호 - 분위기는 [밝고 따뜻하게, 초록색 계열] - 폰에서 열어도 잘 보이게 [꼭 지킬 것] - html 파일 하나로 만들어줘 - 인터넷에서 따로 불러오는 것 없이 만들어줘
  • 오른쪽에 표지가 떴는지
  • 화살표 단추를 눌러 8장까지 넘어가는지
  • 내가 부탁한 내용이 다 들어갔는지

⚠ 클로드는 날짜·장소·숫자를 그럴듯하게 지어낼 수 있습니다. 내가 알려 주지 않은 숫자는 꼭 확인하세요.

4

원하는 곳만 고치기

15분

다시 만들어 달라고 하지 않습니다. 고칠 곳만 말합니다. 아래에서 필요한 것만 골라 쓰세요.

고치기 ① 글씨
모든 장의 글씨를 지금보다 한 단계 크게 해줘. 나머지는 그대로 둬.
고치기 ② 색
색만 [바다 느낌의 파란색] 계열로 바꿔줘. 내용은 그대로 둬.
고치기 ③ 한 장 더
[5장] 뒤에 [회원들이 한 말 한마디] 장을 하나 더 넣어줘. 쪽 번호도 맞춰줘.
고치기 ④ 한 장만 바꾸기
[3장] 의 내용을 [모임 규칙 세 가지] 로 바꿔줘. 다른 장은 건드리지 마.
고치기 ⑤ 재미 한 스푼
장이 넘어갈 때 부드럽게 넘어가는 효과를 넣고, 표지에 어울리는 이모지를 크게 하나 넣어줘.
🔑 주문 공식 — "[어디]를 [어떻게] 바꿔줘. 나머지는 그대로 둬."
5

내 컴퓨터로 내려받아 열어 보기

7분
  1. 아티팩트 오른쪽 위 다운로드(↓) 단추 → 파일 받기
  2. 다운로드 폴더에서 받은 파일을 더블클릭 → 크롬에서 열리면 성공
  3. 파일 이름을 index.html 로 바꾸기 (오른쪽 단추 → 이름 바꾸기)
왜 index인가요? — 인터넷에서 "이 주소의 첫 화면"이라는 약속된 이름입니다. 이렇게 해 두면 주소 뒤에 아무것도 안 붙여도 바로 열립니다.

"html이 안 보여요" → 확장자가 숨겨진 것입니다. index 까지만 바꾸면 됩니다.

다운로드가 안 되면 → 위의 예시 파일 내려받기로 받아서 오늘 연습을 이어 가세요.

인터넷에 올리기 — 내 주소 받기

오늘의 핵심22분

무료 사이트 넷리파이(Netlify)를 씁니다. 카드 등록도, 어려운 설정도 없습니다.

① 가입 (처음 한 번만)

들어가기주소창에 app.netlify.com/signup
가입Sign up with Email → 이메일·비밀번호 입력 (Google 단추가 보이면 그걸 눌러도 됩니다)
메일 확인내 메일함에 온 Netlify 메일 → Verify email 누르기
질문 화면무엇을 만드는지 묻는 영어 질문이 나오면 아무거나 고르고 Continue / Skip

② 올리기 — 끌어다 놓기 한 번

들어가기주소창에 app.netlify.com/drop
놓기5번에서 만든 index.html 파일을 가운데 Drop here 칸으로 끌어다 놓기
기다리기몇 초 뒤 ○○○.netlify.app 주소가 생깁니다 — 눌러서 열어 보기!

③ 주소를 내 이름으로 바꾸기

들어가기화면의 Project configuration(또는 Site configuration) 누르기
바꾸기Change project name → 영어 소문자·숫자·붙임표(-)로 입력 → Save
이름 예시jeju-hanla-walk → jeju-hanla-walk.netlify.app

"이미 있는 이름"이라고 나오면 뒤에 숫자를 붙이세요 — jeju-hanla-walk-1014

⚠ 올린 발표자료는 주소를 아는 누구나 볼 수 있습니다. 전화번호·집 주소 같은 개인정보는 넣지 마세요.
